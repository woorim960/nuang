# 뉴앙 공식 생활 성향 검사 기준

## 기준 검사

- 고객용 이름: `위로받을 때 필요한 것`
- 내부 슬러그: `comfort-style`
- 목적: 최근 힘들었던 상황에서 어떤 도움의 내용이 필요했고, 어떤 방식으로 도움받고 싶었는지 돌아본다.
- 결과의 성격: 최근 6개월 자기보고에 기반한 생활 성향 결과

이 검사는 위로를 받는 능력, 정신건강 상태, 관계의 좋고 나쁨, 고정된 성격을 평가하지 않는다. 실제로 받은 도움이 얼마나 효과적이었는지도 측정하지 않는다.

## 전문가 합의

심리학, 성향검사 설계, 일반 고객 관점의 독립 감사를 거쳐 다음 기준을 확정했다.

1. 검사 제목과 문항을 `도움의 필요도`로 통일한다.
2. 도움을 실제로 받지 못한 사람도 같은 기준으로 답할 수 있어야 한다.
3. 도움의 내용과 도움을 받는 조건을 결과에서 구분한다.
4. 필요도 점수로 실제 위로의 시간 순서를 추론하지 않는다.
5. 답하지 못한 상황은 중간값으로 채우지 않는다.
6. 뉴앙 코드는 점수를 만들거나 바꾸지 않고, 결과를 표현하는 참고 정보로만 사용한다.
7. 완료 당시 결과와 뉴앙 코드를 원본 스냅샷으로 보관한다.

## 측정 구조

네 가지 공통 상황에서 세 요소를 한 번씩 묻는 `4 × 3 = 12문항` 구조를 사용한다.

### 공통 상황

1. 가까운 사람과 오해가 생겨 마음이 복잡했을 때
2. 해야 할 일이 겹쳐 무엇부터 할지 막막했을 때
3. 중요한 결정을 앞두고 걱정이 많아졌을 때
4. 실수해 자신감이 떨어졌을 때

### 도움의 내용

- 마음 알아주기: 판단하지 않고 내 이야기와 마음을 들어주는 도움이 얼마나 필요했는가
- 방법 함께 찾기: 막힌 부분, 선택지, 다음 행동을 함께 정리하는 도움이 얼마나 필요했는가

### 도움을 받는 방식

- 내 속도 지켜주기: 말할 시점과 도움의 종류를 내가 고를 수 있는 방식이 얼마나 필요했는가

`내 속도 지켜주기`는 도움의 종류가 아니라 전달 조건이므로, 마음 알아주기·방법 함께 찾기와 같은 순위로 표시하지 않는다.

## 응답 척도

질문:

> 그 상황에서 이런 도움이 얼마나 필요했나요?

선택지:

1. 전혀 필요하지 않았어요
2. 별로 필요하지 않았어요
3. 어느 정도 필요했어요
4. 꽤 필요했어요
5. 매우 필요했어요

점수는 각각 `0 / 25 / 50 / 75 / 100`으로 변환한다.

## 판단하기 어려운 상황

- 비슷한 경험이 거의 없음
- 상황마다 많이 다름
- 문장이 이해되지 않음
- 답하고 싶지 않음

한 상황의 세 문항 가운데 하나라도 유효한 답이 없으면, 그 상황 전체를 세 요소 비교에서 제외한다. 서로 다른 상황 집합으로 계산한 세 평균을 비교하지 않는다.

- 완전한 상황 3개 이상: 상세 결과 제공
- 완전한 상황 2개 이하: 상세 결과를 만들지 않고 다시 검사할 수 있도록 안내
- 결측값을 중간값으로 대체하지 않음

## 결과 리포트 구조

1. 이번 결과 한눈에 보기
2. 도움의 내용
   - 마음 알아주기
   - 방법 함께 찾기
3. 도움을 받는 방식
   - 내 속도 지켜주기
4. 상황별 차이
5. 가까운 사람에게 보여줄 한 문장
6. 가족·친구·연인·학교·팀·업무 활용 예시
7. 도움이 어긋났을 때 확인할 점
8. 다음 힘든 날 써볼 한마디
9. 내 뉴앙 코드로 함께 보기
10. 안전하게 도움을 요청하는 기준

### 해석 금지

- 높은 필요도 = 반드시 먼저 받아야 하는 도움
- 낮은 필요도 = 반대 도움을 좋아함
- 세 점수의 평균 = 위로 능력 총점
- 뉴앙 코드 때문에 특정 도움이 필요함
- 가족·친구·연인에게 실제로 항상 같은 모습이 나타남

## 개인화 경우의 수

각 요소의 다섯 구간을 조합한 `5 × 5 × 5 = 125개` 기본 조합을 모두 검증한다.

추가 검증:

- 세 요소 동점
- 두 요소가 12점 이내로 비슷한 경우
- 세 요소 모두 낮음
- 세 요소 모두 높음
- 완전한 상황 3개와 4개
- 같은 평균이지만 상황별 응답이 다른 경우
- 뉴앙 코드 32개
- 본인 리포트와 상대 공개 리포트

## 공유·기록 원칙

- 모든 공유는 별도 요약 리포트가 아닌 원본 결과 리포트로 이동한다.
- 공유 카드에는 검사명, 핵심 결과, 세 요소 점수, 바로 쓸 수 있는 한 문장을 제공한다.
- 결과 주인의 완료 당시 뉴앙 코드를 사용한다.
- 보는 사람의 현재 코드로 리포트를 다시 만들지 않는다.
- 프로필에서 리포트별 공개·비공개를 바꿀 수 있다.
- 최신 완료 결과가 내 기록 상단에 표시된다.

## 공통 컴포넌트 계약

새로운 독립 화면이나 검사별 복제 컴포넌트를 만들지 않는다.

- 검사 목록: `AssessmentHub`
- 문항 진행: `FreeTopicRunner`
- 문항 헤더·본문·응답·판단 어려움·종료 팝업: `AssessmentQuestionControls`
- 결과 화면: `FreeTopicResultView`
- 공유: `ReportShareSheet`
- 저장·동기화: `free-topic-storage`와 `/api/free-topic-results`
- 공개 프로필 결과: 동일한 원본 결과 뷰의 읽기 전용 모드

검사별로 달라지는 것은 데이터 계약, 문항, 점수 해석, 리포트 내용, 공유 문구뿐이다.

## 공식 공개 품질 게이트

1. 문항마다 한 가지 중심 내용만 묻는다.
2. 만 14세 미만을 포함해 일반 고객이 이해할 수 있는 문장인지 검토한다.
3. 전문가가 내용의 관련성·포괄성·이해 가능성을 검토한다.
4. 125개 점수 조합과 결측·동점 경우를 자동 테스트한다.
5. 리포트 본문은 2,000자 이상이며 반복 문구와 내부 알고리즘을 노출하지 않는다.
6. 결과 화면, 공유, 프로필, 내 기록이 같은 원본 스냅샷을 사용한다.
7. 모바일 좁은 화면과 키보드·스크린리더 사용성을 확인한다.
8. 공식 노출 전 타입 검사, 관련 단위 테스트, 실제 localhost 흐름을 통과한다.

## 다음 검사에 적용할 순서

2. 측정하는 것과 측정하지 않는 것 구분
3. 심리학 전문가의 구성개념 검토
4. 성향검사 전문가의 문항·척도·채점 검토
5. 일반 고객의 이해도·흥미·공유 욕구 검토
6. 공통 컴포넌트에 데이터만 연결
7. 모든 점수·동점·결측·코드 조합의 리포트 생성
8. 원본 저장·공유·프로필·내 기록 연결
9. 자동 테스트와 실제 화면 검증
10. 공식 검사 탭 공개
