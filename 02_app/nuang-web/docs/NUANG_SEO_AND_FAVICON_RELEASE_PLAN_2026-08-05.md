# 뉴앙 검색 노출·파비콘 출시 기획

- 기준일: 2026-08-05
- 운영 주소: `https://nuang.app`
- 목적: 검색량이 큰 표현을 무관하게 붙이는 것이 아니라, 뉴앙에서 바로 해결할 수 있는 검색 의도와 정확한 페이지를 연결한다.

## 1. 검색 수요 사전 조사

네이버 데이터랩 검색어트렌드에서 2025-08-04~2026-08-04, 전체 기기·성별·연령, 일간 기준으로 비교했다. 데이터랩 값은 절대 검색량이 아니라 조회 기간 중 가장 큰 검색량을 100으로 둔 상대 지수다.

### 넓은 테스트 수요

| 검색 주제군      | 관찰한 상대 범위 | 뉴앙 적용                                                                                         |
| ---------------- | ---------------: | ------------------------------------------------------------------------------------------------- |
| MBTI·성격 유형   |        약 45~100 | 수요는 가장 크지만 뉴앙을 MBTI로 표시하지 않는다. 차이를 설명하는 콘텐츠에서만 사실대로 사용한다. |
| 밸런스 게임      |          약 5~10 | 뉴앙이 직접 해결하는 가장 큰 수요. 메인 유입 페이지로 운영한다.                                   |

| 성향·성격 테스트 |           약 1~3 | 코어검사와 32가지 성향 지도의 핵심 검색 의도다.                                                   |

## 2. 엔진별 구현 원칙

### Google

- 48px 이상 정사각 파비콘과 고정 URL을 제공한다.
- 루트에 `WebSite`, `Organization`, `WebApplication` JSON-LD를 제공해 사이트명 `뉴앙`과 영문명 `NUANG`을 명시한다.
- 공개 페이지별 고유 title·description·canonical·Open Graph를 제공한다.
- sitemap에는 실제 공개·색인 가능한 URL만 포함한다.
- 관리자, API, 개인 결과와 초대 방은 검색 대상에서 제외한다.

### 네이버

- 모든 핵심 페이지의 title과 description을 서로 다르게 작성한다.
- Open Graph 제목·설명·1200×630 이미지를 함께 제공한다.
- robots에서 이미지·정적 리소스 수집을 허용하고 sitemap 위치를 알린다.
- 인기 검색어를 반복하거나 콘텐츠와 무관한 MBTI 키워드를 넣지 않는다.

### 카카오·다음

- 카카오톡 공유와 검색 미리보기가 외부에서 읽을 수 있는 절대 HTTPS 이미지로 연결되도록 한다.
- 기본 공유 이미지는 실제 뉴앙 메인 캐릭터 3종을 사용한 1200×630 이미지로 통일한다.
- 카카오 제품 링크 관리에는 이미 등록한 `https://nuang.app`을 유지한다.
- 다음 검색등록에는 운영 배포 후 루트 주소와 sitemap을 제출한다.

## 4. 파비콘·공유 이미지 체계

- `favicon.ico`: 16·32·48px 다중 크기
- PNG 파비콘: 48·96px
- Apple touch icon: 180px
- 설치 아이콘: 192·512px
- maskable 아이콘: 512px 안전 영역
- 검색·SNS 기본 이미지: 1200×630px
- 모든 자산은 뉴앙 메인 보라 캐릭터와 동일한 보라·아이보리 브랜드 색을 사용한다.
- `npm run seo:assets`로 동일한 결과를 다시 생성할 수 있다.

## 5. 운영자가 마지막으로 해야 하는 일

코드로 대신할 수 없는 검색엔진 계정 소유권 확인만 남는다.

1. Google Search Console에서 `nuang.app` 속성을 추가하고 HTML 태그 방식의 `content` 토큰을 복사한다.
2. 네이버 서치어드바이저에서 `https://nuang.app`을 추가하고 HTML 태그 방식의 `content` 토큰을 복사한다.
3. 토큰을 각각 Vercel의 `GOOGLE_SITE_VERIFICATION`, `NAVER_SITE_VERIFICATION`에 입력하고 다시 배포한다.
4. 두 도구에서 `https://nuang.app/sitemap.xml`을 제출한다.
5. 다음 검색등록에서 `https://nuang.app`을 사이트로 등록한다.

토큰은 공개되어도 인증 비밀번호처럼 계정에 로그인할 수 있는 값은 아니지만, 정확한 사이트 소유권 확인을 위해 운영 환경변수로 관리한다.

## 6. 출시 후 관찰

- Search Console과 네이버 서치어드바이저에서 색인 수, 검색어, 노출, 클릭률, 평균 순위를 주 1회 확인한다.
- 4주 동안 데이터가 쌓이기 전에는 제목을 자주 바꾸지 않는다.
- 노출은 많고 클릭률이 낮으면 제목·설명을 수정하고, 노출 자체가 없으면 sitemap·canonical·본문 일치부터 확인한다.
- 검색어 유입 이후 검사 시작·완료·가입까지는 기존 제품 분석에서 별도로 본다.
