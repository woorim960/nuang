# 뉴앙 함께하기 밸런스 게임 콘텐츠 카탈로그

- 문서 상태: 공개 출시 콘텐츠 레지스트리 운영 기준
- 최근 개정: 2026-07-31
- 상위 기준: `docs/NUANG_TOGETHER_BALANCE_GAME_PRODUCT_SPEC.md`
- 목적: 공개 문항 레지스트리의 검수 상태와 버전 원칙, 팩별 목표, 대표 문항 및 후속 후보를 관리한다.

## 1. 콘텐츠 운영 원칙

문항 풀의 크기와 한 판의 길이는 다르다. 팩에는 수십 개의 검수 완료 문항을 보유하고, 한 판에는 그중 8·16·20·24개를 층화 추출한다.

- 같은 한 판에서 문항을 반복하지 않는다.
- 같은 그룹의 최근 90일 재게임은 문항 중복을 원칙적으로 20% 이하로 유지한다.
- 익숙한 선택, 실제 생활 선택, 이유가 궁금해지는 선택 순서로 배치한다.
- 유명한 문항의 문장을 복사하지 않고 반복되는 소재와 대비 구조만 참고해 다시 쓴다.
- 유행어·브랜드·지역명은 `trend_sensitive`를 표시하고 분기마다 유효성을 검토한다.
- 한쪽이 가격·도덕성·안전성·사회적 선호 때문에 명백히 유리하면 공개하지 않는다.
- 공개 시작 목표를 채우지 못해도 약한 문항으로 수를 맞추지 않는다.
- 공개된 `contentPoolVersion`의 문항 문구·선택지·채점 의미는 수정하지 않는다. 문구 하나라도 달라지면 새 버전을 발행하고 기존 방은 생성 당시 버전에 고정한다.

아래 팩별 문항 표는 소재와 문체를 빠르게 검토하기 위한 `대표 표`이며 312개 전체를 중복 기재하는 실행 원본이 아니다. 대표 표를 런타임에서 파싱하거나 seed로 사용하지 않는다. 실제 공개 문항의 추가·교체는 이 문서의 레지스트리 원장에 버전과 검수 상태를 먼저 기록한 뒤 코드 canonical registry에 반영하고, 두 자료의 팩별 수량·버전 검사를 통과해야 한다.

현재 합계는 정확히 312개다. `출시 전 콘텐츠 검수 완료`는 중복 ID·중복 문항·선택지 겹침·모바일 길이·전 연령 안전·팩 의미·채점 의미를 코드와 문서 기준으로 통과했다는 뜻이다. 실제 선택 분포와 모호성은 공개 운영 데이터가 있어야 판단할 수 있으므로 `운영 보정 완료`를 뜻하지 않는다.

`후보`와 `검수 완료`는 다르다. 위 원장에 없는 1차 확장·90일 확장 문항은 후보이며 표현·겹침·안전성·모바일 가독성 검수와 공개 운영 절차를 거쳐야 canonical registry에 들어간다.

후속 후보:

- 우리 뭐 살까?: 옷·전자기기·생활용품·선물
- 우리 카페 갈까?: 음료·디저트·좌석·분위기·체류 방식
- 반려생활 맞을까?: 산책·놀이·청소·여행·돌봄 기준
- 우리 운동할까?: 운동 종목·강도·시간·경쟁·기록
- 추억 소환전: 학교·간식·놀이·온라인 문화의 세대별 버전
- 계절 한정전: 장마·여름휴가·가을 나들이·연말·새 학기
- 우리 가족 취향: 식사·외출·휴일·사진·명절의 전 연령 문항
- 첫 만남 아이스브레이커: 가볍고 설명하기 쉬운 문항만 선별
