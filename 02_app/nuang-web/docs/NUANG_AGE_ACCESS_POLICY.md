# 뉴앙 베타 연령별 이용 정책

- 적용 버전: `nuang-beta-v1.0`
- 적용일: 2026-08-05
- 외부 법률 검토: 유예 · 승인 아님

## 1. 핵심 원칙

- 홈, 커뮤니티 열람, 뉴앙 코드 검사와 일반 성향 콘텐츠는 로그인 없이 이용할 수 있다.
- 만 14세는 콘텐츠 등급이 아니라 아동 개인정보 처리 시 법정대리인 동의가 필요한 기준이다.
- 만 19세는 모든 검사에 적용하지 않는다. 운영자가 민감 검사로 명시한 개별 검사에만 성인 인증을 적용한다.
- `주의가 필요한 문구`와 `19세 이상 전용`은 서로 다른 정책이다. 주의 문구가 있다는 이유만으로 성인 전용이 되지 않는다.
- 이번 베타는 법정대리인 동의·확인 절차를 제공하지 않으므로 회원가입과 계정 저장은 만 14세 이상 자기확인을 마친 이용자에게만 제공한다.

## 2. 만 14세 이상 회원

- 가입 화면에서 만 14세 이상임을 사실대로 확인하고 최신 이용약관·개인정보 처리방침에 동의해야 계정을 만든다.
- 로그인, 결과 동기화, 게시물·댓글·투표·반응·저장·팔로우 등 계정 기반 기능은 이 가입 절차를 통과한 회원에게 제공한다.
- 선택 분석·마케팅 동의를 거부하거나 철회해도 로그인과 핵심 기능은 그대로 이용할 수 있다.

## 3. 만 14세 미만 회원

- 일반 콘텐츠는 볼 수 있다.
- 로그인 없이 일반 검사를 이용하고 결과를 자신의 브라우저에만 저장할 수 있다.
- 회원가입, OAuth 로그인, 서버 결과 동기화, 게시물·댓글·투표·반응·저장·팔로우 등 계정·커뮤니티 저장 기능은 제공하지 않는다.
- 법정대리인 동의 및 동의 확인 절차가 완성되고 외부 법률 검토를 다시 열기 전에는 만 14세 미만 계정을 임의로 만들지 않는다.
- 정확한 생년월일과 인증 원문은 최소 수집 원칙에 따라 장기 보관하지 않는다.

## 4. 19세 이상 전용 검사

- 검사별 `ageAccessPolicy`가 `adult_verification_required`일 때만 성인 인증을 요구한다.
- 현재 공개된 모든 검사는 `all_ages`이며, `adult_verification_required` 검사는 작성·검수만 가능하고 목록과 직접 주소 모두 비공개다.
- 사이코패스·소시오패스처럼 낙인이나 오해 위험이 큰 후보 검사는 문항 타당도, 결과 안전 문구, 위기 대응, 개인정보 처리 검토를 마친 뒤 운영자가 성인 전용 여부를 결정한다.
- 단순한 체크박스를 성인 인증으로 부르지 않는다. 인증 사업자나 신뢰 가능한 연령 확인 수단이 연결되기 전에는 성인 전용 검사를 공개하지 않는다.

## 5. 운영 데이터

- 일반 검사: `all_ages`
- 성인 인증 필요 검사: `adult_verification_required`
- 성인 인증 결과에는 인증 여부, 인증 시각, 인증 수단, 만료 시각만 저장한다.
- 주민등록번호, 인증 응답 원문, CI 등 불필요한 식별 정보는 앱 데이터로 저장하지 않는다.
