# 뉴앙 스토어 심사 메모

기준일: 2026-08-11<br>
초기 심사 언어: 한국어, 필요한 경우 아래 내용을 영어로 함께 제공

## 1. 심사자에게 먼저 알릴 내용

뉴앙은 만 14세 이상 사용자를 위한 성향 기반 SNS입니다. 일부 성향 검사, 밸런스 게임과 공개 공유 리포트는 로그인 없이 사용할 수 있습니다. 로그인하면 검사 결과 저장·다른 기기 복원·프로필 공개 범위 관리·커뮤니티 작성 기능을 사용할 수 있습니다.

검사 결과는 자기이해와 대화를 돕는 정보이며 의료·심리 진단이 아닙니다. 19세 이상 전용 기능은 초기 버전에 포함하지 않습니다.

## 2. 주요 심사 동선

1. 홈 → 검사 → 코어 검사 또는 주제 검사 시작
2. 비회원으로 검사 완료 → 결과 리포트 확인 → 공유 버튼 확인
3. 결과 리포트의 `로그인하고 결과 저장` → OAuth → 같은 리포트 복귀
4. 마이 → 내 기록 → 저장된 리포트 확인
5. 마이 → 설정 → 로그인 계정 → 계정 삭제
6. 커뮤니티 → 글/댓글/신고/차단 동작 확인
7. 함께하기 → 밸런스 게임 방 생성·참여·최종 결과 확인

공개 웹 계정 삭제 안내: `https://nuang.app/help/account-deletion`

## 3. 로그인

- iOS: Apple, Google, Kakao를 동등한 선택지로 제공한다.
- Android: Google, Kakao, Apple을 제공한다.
- Apple 로그인은 App ID·Services ID·Key와 Supabase Provider 설정이 완료된 뒤 `NEXT_PUBLIC_APPLE_AUTH_ENABLED=true`로 활성화한다.
- OAuth는 시스템 브라우저에서 진행하고 검증된 Universal Link/App Link로 앱의 원래 화면에 돌아온다.
- 인증 코드나 세션 토큰은 화면·로그·URL 복사 UI에 표시하지 않는다.

### 심사용 계정 — 계정 소유자 입력 필요

스토어에 제출할 때 만료되지 않는 전용 심사 계정을 만든다. 개인 운영 계정은 제공하지 않는다.

| 항목                          | 입력 상태                   |
| ----------------------------- | --------------------------- |
| 전용 Google 심사 계정         | `PENDING_ACCOUNT_OWNER`     |
| Apple 심사용 동선             | `PENDING_APPLE_ENROLLMENT`  |
| 2단계 인증/추가 확인이 없는지 | `PENDING_REAL_DEVICE_CHECK` |
| 초기 공개 프로필·검사 기록    | `PENDING_SEED`              |

계정 비밀번호·OTP·복구 코드는 저장소 문서에 넣지 않고 App Store Connect/Play Console의 비공개 심사 입력란에만 넣는다.

## 4. 광고

- 스토어에서 광고 포함을 선언한다.
- 초기 모바일 출시에서는 직접 배너와 쿠팡 파트너스 제휴 링크만 사용한다.
- 광고에는 `광고` 또는 `광고 · 쿠팡 파트너스`를 표시한다.
- 만 14~18세 계정에는 광고를 노출하지 않는다.
- 검사 문항·검사 진행·결과 리포트·밸런스 게임 진행 화면에는 광고를 넣지 않는다.
- 검사 답변·점수·뉴앙 코드·궁합을 광고 타기팅에 사용하지 않는다.

## 6. 계정 삭제

앱 경로: 마이 → 설정 → 로그인 계정 → 계정 삭제<br>
웹 경로: `https://nuang.app/help/account-deletion`

계정 삭제 시 프로필, 로그인 연결 정보, 검사 결과, 커뮤니티 콘텐츠·관계, 비공개 연락처와 계정 연결 분석 데이터가 영구 삭제됩니다. 같은 OAuth로 재가입할 수 있지만 삭제한 기록은 복구되지 않습니다. 실제 법정 보존 대상이 있을 때만 최소 기록을 분리 보관 후 삭제합니다.

## 7. 심사 전 반드시 교체할 항목

- 전용 심사 계정 상태
- Apple Team ID와 실제 서명 인증서
- Android App Link의 Play App Signing SHA-256 인증서 지문
- Store Connect/Play Console의 최신 개인정보 공개 답변
- 실제 빌드의 버전·빌드 번호와 릴리스 노트
- 실기기 테스트 날짜와 증빙
