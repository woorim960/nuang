# 뉴앙 모바일 실제 기기 QA 매트릭스

기준일: 2026-08-11<br>
결과 상태: `미실행`, `통과`, `실패`, `해당 없음` 중 하나만 사용

이 표의 목적은 “한 번 켜 봤다”가 아니라 출시 후 실제 사용자가 겪는 계정·기기·네트워크 조합을 빠짐없이 확인하는 것이다. 실패 항목은 이슈 링크, 재현 영상, 앱 버전, OS, 계정 상태를 함께 남긴다.

| ------- | ------------------------ | ------------------------ | ------ |
| iPhone  | 지원 최저 iOS, 소형 화면 | 레이아웃·성능 하한       | 미실행 |

## 8. 증빙과 최종 승인

각 실패에는 `날짜 / 빌드번호 / 기기 / OS / 계정상태 / 네트워크 / 재현단계 / 기대값 / 실제값 / 영상·로그`를 남긴다. P0·개인정보 항목은 미실행·실패가 하나라도 있으면 출시 승인하지 않는다. 모두 통과하면 `config/mobile-store-profile.json`의 `realDeviceQaPassed`만 증빙 링크와 함께 `true`로 바꾼다.
