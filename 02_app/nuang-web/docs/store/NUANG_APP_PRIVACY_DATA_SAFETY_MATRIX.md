# 뉴앙 App Privacy·Data safety 입력표

> 구현 검증 메모: 뉴앙은 광고 ID·하드웨어 식별자를 수집하지 않는다. IP와 User-Agent로 만든 복원 불가능한 보안 HMAC 및 짧은 광고 세션값은 `Device ID`가 아니라 진단·보안 또는 광고 활동 데이터로 신고한다. iOS 앱에는 이 표와 맞춘 `PrivacyInfo.xcprivacy`가 번들 루트에 포함된다.

## 2. 데이터 유형별 입력

| 데이터 유형                          | 연결 여부            | 공유 여부  | 필수/선택            | 목적                            |
| ------------------------------------ | -------------------- | ---------- | -------------------- | ------------------------------- |
| 사용자 ID·OAuth 식별값               | 계정에 연결          | 공유 안 함 | 계정 생성 시 필요    | 앱 기능, 계정 관리, 보안        |
| 이메일·휴대전화·이름                 | 계정에 연결          | 공유 안 함 | 기능에 따라 선택     | 앱 기능, 계정 관리, 운영 연락   |
| 프로필·게시물 사진                   | 계정에 연결          | 공유 안 함 | 업로드 시 선택       | 앱 기능                         |
| 닉네임·소개·글·댓글·투표·신고·피드백 | 계정에 연결          | 공유 안 함 | 해당 기능 사용 시    | 앱 기능                         |
| 검사 답변·점수·결과·리포트           | 계정에 연결          | 공유 안 함 | 로그인 저장 시       | 앱 기능, 개인화                 |
| 화면 이용·문항 품질 신호             | 계정에 연결          | 공유 안 함 | 분석 동의 시에만     | 분석                            |
| 광고 노출·클릭·숨김·의견             | 계정에 연결하지 않음 | 공유 안 함 | 성인 광고 이용 시    | 광고 운영, 분석, 부정 이용 방지 |
| 오류·기기·브라우저·요청 HMAC         | 계정에 연결하지 않음 | 공유 안 함 | 서비스 과정에서 자동 | 앱 안정성, 보안                 |

`공유 안 함`은 뉴앙이 해당 데이터를 광고주나 제휴사에 전달하지 않는다는 뜻이다. Supabase·Vercel·Resend처럼 뉴앙의 지시로 처리하는 서비스 제공자는 각 스토어 정의에 맞춰 별도 공급자 처리로 대조한다. 사용자가 쿠팡 파트너스 링크를 누르면 시스템 브라우저의 외부 사이트로 이동하며, 외부 사이트의 처리는 해당 사업자의 정책이 적용된다.

## 3. 광고와 미성년자

- 스토어의 `광고 포함` 질문에는 예로 답한다.
- 초기 모바일 출시의 광고 공급자는 직접 배너와 쿠팡 파트너스만 허용한다.
- Google AdSense는 코드가 fail-closed로 존재하지만 초기 모바일 출시에서는 비활성화한다.
- 서버는 연령대가 `14-18`인 계정과 운영자 계정에 광고를 반환하지 않는다.
- 검사 답변·점수·뉴앙 코드·궁합은 광고 타기팅이나 광고주 보고서에 쓰지 않는다.
- 광고 공급자, SDK, 처리 목적이 바뀌면 스토어 공개표를 먼저 갱신한 뒤 배포한다.

## 4. Apple App Privacy 입력 순서

1. Data Collection은 `Yes`를 선택한다.
2. JSON의 `appleType`별로 수집 목적과 사용자 연결 여부를 입력한다.
3. Tracking은 초기 모바일 구성 기준 `No`를 선택한다.
4. 개인정보 처리방침 URL과 Privacy Choices URL을 입력한다.
5. Product Page Preview에서 항목이 누락되지 않았는지 확인하고 Publish한다.

## 5. Google Data safety 입력 순서

1. 데이터 수집은 `Yes`, 전송 중 암호화는 `Yes`로 답한다.
2. 계정 생성·삭제 질문에 앱 내 삭제와 웹 삭제 URL을 입력한다.
3. 각 `googleType`을 수집/필수·선택/목적에 맞춰 입력한다.
4. 서비스 제공자 처리와 외부 공유의 정의를 콘솔 최신 안내에서 다시 확인한다.
5. 광고 포함, 타겟층, IARC 등급 설문과 모순이 없는지 확인한다.

## 6. 출시 차단 조건

- 실제 운영 빌드에 목록 밖의 SDK가 포함됨
- AdSense 또는 추적형 광고를 켰지만 Tracking/Data safety를 갱신하지 않음
- 만 14~18세 계정에서 광고가 노출됨
- 계정 삭제 URL이 로그아웃 브라우저에서 열리지 않음
- 개인정보 처리방침과 스토어 답변의 보유·삭제 설명이 다름
