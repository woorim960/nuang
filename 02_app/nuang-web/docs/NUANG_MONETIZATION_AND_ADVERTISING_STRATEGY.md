# 뉴앙 수익화·광고 발전 전략

- 문서 상태: 전략안·사용자 승인 대기 — 상품·결제·광고 연결 전 별도 승인 필요
- 작성일: 2026-07-31
- 대상 기간: 0~12개월 및 이후 확장
- 연계 문서: `NUANG_ASSESSMENT_FIRST_HOME_RESTRUCTURE_PLAN.md`
- 법률 고지: 이 문서는 제품 전략이며 법률·세무 자문을 대체하지 않는다.

## 0. 결론

뉴앙의 수익화는 배너 광고 하나에 의존해서는 안 된다.

권장 수익 구조는 다음 세 축이다.

1. **보조 수익:** 검사 중심 홈과 커뮤니티의 절제된 문맥형 광고
2. **핵심 B2C 수익:** 광고 제거, 더 많은 놀이 콘텐츠, 기록·재게임·그룹 기능을 묶은 선택형 유료 상품
3. **고성장 B2B 수익:** 브랜드 협업 밸런스 팩, 스폰서 주제, 참여형 캠페인

뉴앙의 무료 핵심 검사와 기본 결과는 사람을 모으는 성장 엔진이다. 이를 결제벽으로 막거나 `돈을 내면 더 정확하다`고 말하면 단기 결제보다 더 큰 신뢰·바이럴 손실이 생긴다.

## 1. 수익화 원칙

### 1.1 지켜야 할 것

- 첫 성향 검사, 정밀 성향 검사, 기본 결과는 무료로 유지한다.
- 유료의 가치는 `더 정확한 사람 판정`이 아니라 콘텐츠 양, 편의, 기록, 함께하기, 표현 방식에 둔다.
- 이미 완료한 검사 결과와 함께하기 밸런스게임에서 이미 생성된 취향 일치 점수·결과를 뒤늦게 결제벽으로 가리지 않는다.
- 초대받은 참여자는 방장이 연 유료 함께하기 콘텐츠를 별도 결제 없이 끝까지 이용한다.
- 광고와 스폰서 콘텐츠는 일반 콘텐츠와 즉시 구분돼야 한다.
- 직접 응답, 원점수, 뉴앙 코드, 관계 결과를 광고 타기팅이나 외부 판매에 사용하지 않는다.
- 사용자가 광고성 소식 수신을 거절해도 핵심 서비스 이용에 불이익을 주지 않는다.
- 현재 개인정보 안내의 `회원이 직접 공유하거나 법령상 근거가 있는 경우를 제외하고 개인정보를 다른 회사에 판매하거나 제공하지 않는다`는 약속을 수익화 이후에도 유지한다.

### 1.2 하지 않을 것

- 결과를 일부 가린 뒤 불안을 자극해 결제를 유도
- 낮은 궁합·부족한 성향을 해결해 준다며 결제 압박
- 성향 결과를 보험, 대출, 채용, 가격 차별에 제공
- 개인별 성향 데이터를 광고주에게 판매
- 아동·청소년에게 부적절한 업종 광고 노출
- 검사 문항·게임 선택 화면의 배너나 전면 광고
- 결과를 보려면 광고를 강제로 끝까지 시청하게 하는 구조

## 3. 권장 수익화 우선순위

### 3.1 1순위 — 공식 스폰서 밸런스 팩

밸런스 게임은 브랜드가 자연스럽게 참여할 수 있으면서도 검사 신뢰를 훼손할 가능성이 낮다.

적합 분야:

- 영화·OTT: `우리 뭐 볼까?`
- 여행·숙박: `우리 어디갈까?`
- 음식·배달·프랜차이즈: `우리 뭐 먹을까?`
- 취미·전시·공연: `우리 뭐할까?`
- 생활용품·패션: 구체적인 취향 선택

상품 구조:

1. 브랜드가 주제를 제공한다.
2. 뉴앙의 문항 품질·밸런스 기준으로 공동 제작한다.
3. 팩 상단에 `광고 · 브랜드명과 함께 만든 팩`을 명확히 표시한다.
4. 브랜드 선택을 정답처럼 유도하지 않는다.
5. 결과 점수 공식은 일반 팩과 동일하게 유지한다.
6. 결과 뒤에는 선택형 쿠폰·이벤트를 별도 영역으로 제공한다.

과금 방식 후보:

- 제작비 + 기간 사용료
- 보장 노출량 기반 캠페인 비용
- 참여 완료 기반 성과 비용
- 쿠폰 사용·전환에 대한 제휴 수익

특정 브랜드 상품 두 개만 억지로 양자택일시키기보다, 브랜드가 후원하는 넓은 주제 안에서 실제로 재미있는 선택을 제공해야 한다.

### 3.2 2순위 — 프리미엄 팩과 방장 패스

무료 사용자는 공개 기본 팩을 충분히 즐길 수 있어야 한다.

유료 가치:

- 시즌·콜라보·크리에이터 프리미엄 팩
- 긴 게임과 사용자 지정 팩 조합
- 같은 멤버 재경기와 결과 히스토리
- 모임용 진행 화면과 발표용 결과
- 방 꾸미기, 결과 카드 테마
- 광고 없는 함께하기 경험

핵심 규칙:

- 방장이 결제하면 초대 참여자는 무료
- 이미 시작한 방의 결과는 결제 만료 후에도 열람 가능
- 무료 팩의 기본 기능을 유료 출시와 함께 축소하지 않음

### 3.3 3순위 — 뉴앙 플러스

구독은 지속적인 가치가 준비됐을 때만 연다.

포함 후보:

- 전 서비스 광고 제거
- 매월 새 프리미엄 팩
- 성향·주제 결과의 장기 변화 기록
- 리포트 보관·검색·비교 히스토리
- 그룹 놀이 기능과 방장 혜택
- 추가 결과 카드·프로필 표현
- 정기적인 회고 질문과 개인 메모

포함하지 않을 것:

- 유료 사용자만 정확한 대표 코드
- 무료 사용자보다 높은 신뢰도 점수
- 기본 결과 해석 잠금
- 커뮤니티 노출 우대 판매

Apple은 구독에 지속적이고 실질적인 가치를 요구하며, 가격·기간·제공 내용을 결제 전에 명확히 안내하도록 요구한다. 네이티브 앱 출시 시 [App Review Guidelines](https://developer.apple.com/app-store/review/guidelines/)와 [구독 안내](https://developer.apple.com/app-store/subscriptions/)를 상품 계약에 반영한다.

### 3.4 4순위 — 유료 생활형 확장 리포트

유료 리포트는 진단이나 더 정확한 성향 판정이 아니라 활용 도구다.

허용 예:

- 상황별 행동 패턴을 더 길게 정리한 읽기 자료
- 장점과 주의점을 실행으로 옮기는 7일 실험
- 대화·협업·휴식·정리 등 주제별 체크리스트
- 결과의 시간별 변화 기록과 개인 메모
- 두 사람이 함께 쓰는 대화 카드

금지 예:

- `결제하면 숨겨진 진짜 성격 공개`
- 불안을 자극하는 일부 결과 블러
- 결과가 나쁘니 개선 상품이 필요하다는 압박
- 검증되지 않은 임상·채용 적합성 판정

## 4. 광고 전략

### 4.1 광고의 역할

배너 광고는 초기 현금흐름의 보조 수단이다. DAU가 작을 때 배너만으로 의미 있는 사업을 만들기 어렵기 때문에, 광고 배치를 늘리기보다 검사 시작·완주·재방문을 키우는 것이 먼저다.

광고의 우선순위:

1. 직접 판매한 스폰서 팩
2. 직접 판매한 문맥형 브랜드 배너
3. 트래픽과 동의 기반이 준비된 뒤 품질을 통제할 수 있는 광고 네트워크
4. 개인 추적 기반 고단가 광고는 당분간 사용하지 않음

### 4.2 1차 광고 인벤토리

| 인벤토리              | 형식                      | 시작 조건                            | 빈도                       |
| --------------------- | ------------------------- | ------------------------------------ | -------------------------- |
| `HOME_INLINE_01`      | responsive inline banner  | 코어·주제·함께하기 노출 뒤           | 홈 방문당 최대 1회         |
| `HOME_INLINE_02`      | responsive inline banner  | 01의 잔존율 영향 통과 후             | 긴 홈 세션만               |
| `FEED_INLINE_01`      | 명확히 구분된 인피드 광고 | 충분한 피드 밀도와 세션 길이 확보 후 | 최소 8~12개 유기적 항목 뒤 |
| `HOME_SPONSORED_PACK` | 스폰서 팩 카드            | 직접 브랜드 계약 후                  | 일반 추천과 별도 라벨      |

### 4.3 광고 배치 안전 규칙

- 광고보다 유기적 콘텐츠가 항상 많아야 한다.
- 광고와 버튼·탭·게임 선택 영역 사이에 명확한 여백을 둔다.
- 광고 영역을 미리 예약해 콘텐츠 밀림과 오클릭을 막는다.
- 광고가 앱 콘텐츠처럼 보이게 만들지 않는다.
- 하단 탭바와 붙는 anchored banner를 사용하지 않는다.
- 문항, 결과 핵심, 오류 화면에는 광고를 넣지 않는다.

Google도 모바일 광고는 상호작용 요소와 분리하고, 콘텐츠보다 광고가 많지 않게 하며, 광고임을 쉽게 구분하도록 권고한다. [AdSense 배치 원칙](https://support.google.com/adsense/answer/1282097), [AdMob 배너 가이드](https://support.google.com/admob/answer/6128877), [고정 공간 권고](https://support.google.com/admob/answer/6275335)를 운영 기준으로 삼는다.

### 4.4 광고 품질 차단 목록

전 연령 공개 표면의 기본 차단:

- 도박·베팅·카지노
- 고금리 대출·불법 금융·가상자산 투기 조장
- 성인·성적 만남·선정적 콘텐츠
- 주류·담배·전자담배
- 정치 선전
- 검증되지 않은 의료·정신건강 진단·치료
- 외모·체중·열등감을 자극하는 과장 광고
- 성격·궁합을 운명이나 성공 보장으로 표현하는 상품
- 다운로드·시스템 경고로 위장한 광고

19세 이상 업종은 별도 인증 표면이 생기더라도 개별 정책 승인을 거친다.

### 4.5 타기팅 데이터

초기 허용:

- 광고 슬롯 ID
- 화면의 넓은 문맥 분류
- 언어
- 기기 폭 범주
- 캠페인·소재 ID

수집 금지:

- 검사 선택지와 응답 시간
- 점수와 뉴앙 코드
- 결과 리포트 문장
- 비교 상대와 궁합 점수
- 민감 주제 이용 기록
- 연락처·이메일·OAuth 원문

외부 광고 SDK가 자체 식별자나 행태정보를 처리할 경우 별도 동의, 개인정보 처리방침, 철회 경로, 공급자 계약 검토를 완료하기 전 연결하지 않는다. 국내 온라인 맞춤형 광고 정책은 계속 정비 중이므로 초기에는 문맥형·비개인화 광고를 기본값으로 사용한다. 참고 기준은 [온라인 맞춤형 광고 개인정보보호 가이드라인](https://www.kmcc.go.kr/user.do?boardId=1099&boardSeq=44473&mode=view&page=A02030700)과 개인정보보호위원회의 최신 안내를 배포 시점에 다시 확인한다.

### 4.6 광고 성과 측정 계약

초기 직접 광고는 회원을 따라다니는 추적이 아니라 캠페인 단위의 노출·클릭 집계로 측정한다.

허용 이벤트 필드:

- 짧게 만료되는 무작위 세션 토큰
- 캠페인 ID, 소재 ID, 슬롯 ID
- `home_recommended`처럼 사전에 허용한 넓은 문맥 코드
- 노출·클릭·숨김·신고 이벤트 종류
- 분 단위가 아닌 넓은 시간 bucket
- 기기 폭 범주와 앱 버전

금지 이벤트 필드:

- account ID, 이메일, 전화번호, 영구 기기 식별자
- 원문 URL, referrer, 검색어
- 검사 ID·응답·점수·코드·리포트 문장
- 밸런스게임 방 ID, 참여자 ID, 상대·그룹 결과
- 자유 입력 텍스트와 광고주가 임의로 추가한 query parameter

보존 제안:

- 원시 광고 이벤트: 오류 조사와 부정 클릭 점검에 필요한 30일 후 삭제
- 개인을 식별하지 않는 캠페인 집계: 성과 비교를 위해 13개월 보존
- 광고주 제공: 최소 집계 단위의 캠페인 보고서만 제공

위 기간은 제품 제안값이며 실제 적용 전 개인정보 처리방침, 공급자 계약, 삭제·열람 요청 처리 절차와 함께 승인한다. 보존 목적이 끝난 데이터는 삭제하고, 원시 로그를 장기 분석 테이블로 복제하지 않는다.

## 5. 브랜드 협업 원칙

### 5.1 스폰서 표시

- 사용자가 첫 화면에서 경제적 이해관계를 알아볼 수 있게 한다.
- 긴 설명 끝이나 접힌 영역에만 숨기지 않는다.
- 일반 배너는 `광고`, 협업 팩은 `광고 · 브랜드명과 함께 만든 팩`으로 명확히 표시한다.
- 뉴앙의 편집 추천과 광고주의 유료 노출을 같은 라벨로 섞지 않는다.

공정거래위원회의 추천·보증 표시·광고 기준도 경제적 이해관계를 소비자가 쉽게 인식할 수 있게 공개하는 방향이다. 운영 전 [현행 심사지침](https://www.law.go.kr/LSW/admRulSc.do?query=%EC%B6%94%EC%B2%9C%E3%86%8D%EB%B3%B4%EC%A6%9D+%EB%93%B1%EC%97%90+%EA%B4%80%ED%95%9C+%ED%91%9C%EC%8B%9C%E3%86%8D%EA%B4%91%EA%B3%A0+%EC%8B%AC%EC%82%AC%EC%A7%80%EC%B9%A8)을 법무 검토한다.

### 5.2 검사 독립성

- 스폰서가 결과 유형, 점수 공식, 특정 선택의 긍정·부정 해석을 구매할 수 없다.
- 광고 캠페인 성과와 검사 품질 검수는 다른 담당자가 승인한다.
- 스폰서 팩도 일반 팩과 동일한 문항 균형·이해도·전 연령 기준을 통과한다.
- 브랜드 요청으로 질문을 모호하게 만들거나 특정 제품 선택을 정답처럼 만들지 않는다.

### 5.3 쿠폰·전환 측정 경계

- 쿠폰은 결과 확인 뒤 사용자가 명시적으로 선택할 때만 연다.
- 쿠폰 코드나 전환 token에 회원 ID, 뉴앙 코드, 문항 응답, 방 ID, 참여자 목록을 넣지 않는다.
- 가능하면 한 번 쓰고 만료되는 비식별 token 또는 캠페인 집계만 사용한다.
- 쿠폰 사용자를 다시 추적해 성향 기반 광고 audience로 만들지 않는다.
- 광고주가 개인 연락처나 신청 정보를 받아야 하는 캠페인은 뉴앙 기본 계정 정보와 분리된 별도 동의, 수집 화면, 이용 목적, 보존 기간을 제시하고 다시 승인받는다.
- 광고주에는 개인별 선택 결과가 아니라 계약된 최소 집계 성과만 제공한다.

## 6. 가격 실험 가설

아래 가격은 확정안이 아니라 지불 의사 검증용 범위다.

| 상품             | 실험 범위             | 검증할 질문                                   |
| ---------------- | --------------------- | --------------------------------------------- |
| 단일 프리미엄 팩 | 2,900~5,900원         | 한 번의 새 놀이에 지불하는가                  |
| 방장 패스        | 3,900~7,900원         | 모임 전체 무료 참여 가치가 있는가             |
| 뉴앙 플러스 월간 | 4,900~6,900원         | 광고 제거·신규 팩·기록이 반복 가치를 만드는가 |
| 뉴앙 플러스 연간 | 월간 대비 25~35% 할인 | 장기 기록 가치가 연간 유지로 이어지는가       |

가격 테스트 원칙:

- 실제 판매 전에는 `출시 예정`, 예상 가격, 제공 가치를 정직하게 밝힌 미리보기와 알림 신청으로 수요를 확인한다. 결제가 가능한 것처럼 보이는 가짜 구매 버튼은 사용하지 않는다.
- 가격별 클릭뿐 아니라 실제 결제 완료·30일 사용·환불을 본다.
- 연간 가격은 월 환산액보다 실제 청구 총액을 더 분명하게 표시한다.
- 무료 체험 후 결제일, 가격, 해지 방법을 명확히 안내한다.

### 6.1 결제·구독 출시 gate

웹·iOS·Android 중 하나라도 실제 결제를 열기 전에 아래 계약을 확정한다.

- 자동 갱신 여부, 실제 청구 총액, 결제 주기, 다음 결제일을 구매 전에 표시
- 무료 체험의 유료 전환 시점과 가격 변경 규칙 고지
- 앱 안에서 현재 구독 상태, 다음 결제일, 해지 경로 확인
- 청약철회·환불·콘텐츠 사용 후 처리 기준 고지
- 구독 만료 뒤에도 기존 무료 결과와 이미 생성된 함께하기 결과 열람 유지
- 플랫폼 간 entitlement 복원, 중복 결제 방지, 구매 복구
- `광고 제거 단품`, `뉴앙 플러스`, `방장 패스`의 권리 중첩과 상향 전환 규칙

네이티브 앱에서는 디지털 상품의 결제 방식과 외부 결제 링크가 플랫폼 정책에 맞는지 출시 국가별로 재확인한다. 기준 문서는 Apple [App Review Guidelines](https://developer.apple.com/app-store/review/guidelines/)와 Google Play [결제 정책](https://support.google.com/googleplay/android-developer/answer/9858738?hl=ko)이다.

## 7. 0~12개월 로드맵

### 0~3개월 — 성장 기반과 광고 안전 설계

목표:

- 검사 중심 홈으로 정체성 명확화
- 홈의 첫 광고 인벤토리 한 개만 기술적으로 준비
- 성향 데이터와 광고 데이터를 분리
- 브랜드 협업 팩 영업용 제안서와 제작 프로세스 확립

기반 구현:

- 공급자 독립형 `HOME_INLINE_01` 슬롯
- 광고 loading/no-fill/error 기반
- 광고 차단 업종과 캠페인 검수표
- 스폰서 팩 표시 규칙

실제 광고 소재 송출 조건:

- 캠페인 계약, 경제적 이해관계 표시, 개인정보 검토, 업종·소재 검수가 모두 승인됨
- 직접 등록한 문맥형 소재부터 시작함
- 프로그램매틱 광고 연결은 데이터 흐름과 동의 UI를 포함한 별도 사용자 승인을 받음

아직 열지 않음:

- 개인 맞춤 광고
- 구독 결제
- 결과 화면 광고
- 통계형 브랜드 인사이트 제공

Gate:

- 홈의 검사 시작률과 D1 유지가 광고 없는 기준보다 의미 있게 악화되지 않음
- 오클릭 의심과 정책 위반 0건

### 3~6개월 — 첫 직접 수익

목표:

- 광고 네트워크보다 단가와 품질을 통제하기 좋은 직접 협업 시작
- 밸런스 게임의 반복 플레이를 수익으로 연결

출시 후보:

- 첫 공식 스폰서 팩
- 프리미엄 팩 또는 방장 패스 1종
- 광고 제거를 포함한 뉴앙 플러스 관심 알림 신청
- 브랜드 쿠폰·이벤트의 선택형 연결

Gate:

- 스폰서 팩 완주율이 일반 팩과 유사
- 광고 표시 이해도 90% 이상
- 초대 참여자의 결제 이탈 없음

초기에는 `광고 제거 단품`과 `뉴앙 플러스`를 동시에 팔지 않는다. 광고 제거 권리를 어떤 상품이 소유하는지, 기존 구매를 구독으로 전환할 때 중복 결제가 생기지 않는지 먼저 확정한다.

### 6~12개월 — 반복 매출

목표:

- 충분한 월별 새 콘텐츠와 기록 가치를 확보한 뒤 구독 검증
- 직접 광고·B2C 상품의 균형

출시 후보:

- 뉴앙 플러스
- 결과·함께하기 히스토리
- 매월 프리미엄 팩
- 소규모 모임용 진행 기능
- 제한된 커뮤니티 인피드 광고

Gate:

- 구독자의 2개월차 유지와 실제 반복 사용 확인
- 무료 사용자의 핵심 경험 악화 없음
- 광고 제거가 유의미한 결제 동기인지 확인

### 12개월 이후 — 플랫폼 확장

- 검수된 크리에이터 팩과 수익 배분
- 대규모 오픈 밸런스 캠페인
- 브랜드 전용 참여형 이벤트
- 학교·조직의 비선발·비평가형 관계 워크숍

채용 선발, 인사평가, 보험, 대출, 의료 판정에는 뉴앙 성향 결과를 제공하지 않는다.

조직·학교용 그룹 리포트는 별도 동의, 최소 집단 크기, 작은 셀 숨김을 기본으로 한다. 관리자는 개인 응답이나 개인 순위를 볼 수 없고, 집단 결과로 특정 참여자를 역추정할 수 없어야 한다.

최소 집단 크기와 작은 셀 기준은 숫자로 확정해 별도 사용자 승인을 받기 전까지 상품을 출시하지 않는다. 반복 조회, 필터 조합, 다른 표와의 교차로 개인을 재식별할 수 없는지도 출시 심사에 포함한다.

### 9.1 광고 도메인

ad_delivery_rule
ad_impression

금지:

- 결과 코드별 캠페인 audience 생성
- 광고주에게 row-level 사용자 데이터 export

### 9.2 필요한 운영 기능

- 캠페인 시작·종료
- 슬롯별 소재 preview
- 전 연령·19세 이상 업종 분리
- 업종·도메인 차단
- 노출 빈도 제한
- 긴급 캠페인 중지
- 소재 변경 감사 로그
- 광고 신고·숨기기
- 성능·오류 모니터링

### 9.3 개인정보·플랫폼 gate

- 광고 공급자와 데이터 처리 항목 계약
- 개인정보 처리방침과 동의 UI
- 개인화 광고 opt-in/철회
- 아동·청소년 노출 정책
- Apple ATT 적용 여부
- Android·웹 추적 동의
- 스폰서 경제적 이해관계 표시
- 결제·환불·구독 해지

초기 광고 기반은 제3자 SDK를 바로 삽입하지 않고, 운영자가 승인한 소재 projection을 서버에서 내려주는 공급자 독립형 슬롯으로 시작한다. 프로그램매틱 광고는 트래픽, 동의, 차단 업종, SDK 데이터 흐름을 검증한 다음 단계다.

Apple은 광고·분석 SDK에도 앱과 동등한 개인정보 보호를 요구하고 추적에는 별도 권한이 필요할 수 있다고 안내한다. [개인정보와 데이터 사용](https://developer.apple.com/app-store/user-privacy-and-data-use/)과 최신 App Review Guidelines를 네이티브 출시 전 재검토한다.

### 9.4 통계형 브랜드 인사이트 후보의 추가 gate

`익명 데이터`라는 이름만으로 재식별 위험이 사라지지 않으므로 초기 상품에는 포함하지 않는다. 이후 검토할 때도 다음 조건을 모두 충족해야 한다.

- 사용 목적과 제공 범위를 설명한 별도 동의
- 사용자·응답 단위 export 영구 금지
- 사용자 승인을 받은 숫자형 최소 집단 크기와 작은 셀 숨김
- 반복 query, 교차표, 필터 조합을 통한 재식별 방지
- 결과물의 운영자 사전 검수와 반출 기록
- 채용, 보험, 대출, 의료, 가격 차별 용도 계약 금지
- 동의 철회와 삭제 요청이 후속 집계에 반영되는 절차

이 gate와 법률 검토가 끝나기 전에는 영업 제안서에 판매 가능한 상품으로 기재하지 않는다.

## 10. 실험 중단 기준

다음 중 하나라도 발생하면 광고·상품 실험을 중지하고 원인을 수정한다.

- 홈 → 검사 시작률이 대조군보다 상대 3% 이상 하락
- 검사 완주율이 대조군보다 2%p 이상 하락
- 광고 표시를 일반 검사 추천으로 오인한 사용자 비율이 10% 초과
- 신뢰·도움됨 평가가 사전 기준보다 지속 하락
- 정책 위반, 금지 업종 노출, 성향 데이터가 광고 요청 payload에 포함된 경우는 1건이라도 즉시 중단
- 광고 인접 요소의 반복 오클릭 패턴 확인
- 스폰서 요구로 검사 점수·결과 의미가 변경
- 결제 후 초대 참여자가 추가 결제를 요구받음
- 환불·해지 경로가 결제 경로보다 현저히 어려움

사전에 정한 표본 수와 신뢰구간을 충족하기 전에는 수익이나 CTR만으로 성공을 선언하지 않는다. 보호 지표가 악화되면 매출이 발생해도 실험을 닫는다.

## 11. 최종 권고

1. 새 검사 중심 홈은 광고 매체보다 먼저 뉴앙의 가치를 증명해야 한다.
2. 첫 광고는 홈의 유기적 콘텐츠 뒤 한 슬롯만 연다.
3. 초기 광고는 성향과 무관한 문맥형으로 제한한다.
4. 가장 먼저 적극적으로 판매할 상품은 브랜드 협업 밸런스 팩이다.
5. B2C 유료화는 핵심 검사의 정확도를 파는 방식이 아니라 새 콘텐츠·기록·함께하기 편의를 판다.
6. 구독은 매월 줄 새 가치와 재방문 습관이 확인된 뒤 연다.
7. 개인 성향 데이터 판매와 고위험 의사결정 활용은 영구 금지한다.
