# 뉴앙 집중 전환 제작·운영 명세

- 문서 상태: Production baseline
- 기준일: 2026-07-29
- 상위 표준: `NUANG_TOPIC_ASSESSMENT_PRODUCTION_STANDARD.md`
- 검사 슬러그: `focus-switch`
- 고객용 제목: 집중이 끊기면 나는 어떻게 다시 시작할까?
- 공개 정책: 전 연령, 내부 lifecycle `pilot`

## 1. Stage 0 주제 선정과 사업 가설

### 사용 장면

사용자는 연락이나 요청 때문에 하던 일이 끊겼거나, 끝내지 못한 일을 두고 다른
일로 넘어갔거나, 쉬고 돌아왔거나, 여러 일을 오가다 현재 위치를 놓친 뒤
“어떻게 다시 들어가야 하는지” 알고 싶을 수 있다.

### 완료 가치

검사 완료 후 다음을 얻는다.

1. 중단 전에 다시 시작할 지점을 남기는 정도
2. 중단했던 일을 다시 시작할 때 현재 목표를 잡는 정도
3. 집중할 준비가 완벽해지기를 기다리지 않고 작은 행동으로 시작하는 정도
4. 집중이 끊긴 장면에 따라 위 세 가지 방법이 달라지는 지점
5. 현재 뉴앙 코드의 기본 경향과 실제 다시 시작 방법의 교차 해석

### 제품 연결

- 결과 저장과 성향지도·프로필 리포트 연결
- “집중이 끊긴 뒤 다시 시작하는 방식”을 대화와 공유 소재로 활용
- 같은 버전 재검사 시 생활 조건과 다시 시작하는 방식의 변화 비교
- 문항 체류·수정·판단 어려움·결과 적합도의 운영센터 자동 집계

### 사업 목표

- 예상 소요 시간: 4분
- 문항 수: 12문항
- 시작 대비 내부 목표 완료율: 78% 이상
- 공유 동기: 함께 생활하거나 공부·일하는 사람에게 내 복귀 조건을 설명
- 재방문 동기: 알림·일정·역할이 달라진 뒤 다시 시작하는 방식의 변화 확인
- 연령 정책: `all_ages`

### 포트폴리오 중복 판정

| 인접 검사   | 해당 검사가 보는 것                 | 집중 전환이 보는 것                                |
| ----------- | ----------------------------------- | -------------------------------------------------- |
| 충전 방식   | 피로 뒤 회복 행동                   | 하던 일이 끊긴 뒤 과제로 복귀하는 행동             |
| 기분 전환   | 감정 상태를 바꾸는 방향             | 감정과 무관하게 현재 과제 목표를 재활성화하는 행동 |
| 정리 방식   | 물건·일정·정보를 평소 배치하는 방식 | 중단 시점과 복귀 순간에 사용하는 최소한의 단서     |
| 미루기 패턴 | 시작을 늦추는 여러 조건과 패턴      | 이미 하던 일이 끊긴 뒤 다시 연결하는 구체적 행동   |

따라서 주제를 유지하되 “집중 능력”, “생산성”, “의지”, “주의력 문제”를
측정·평가하지 않는다.

## 2. 구성개념과 경계

### 한 문장 정의

> 최근의 구체적인 과제 중단·복귀 상황에서 사용자가 실제로 사용한 재개 단서,
> 목표 재정렬, 작은 재진입 행동의 정도

### 포함

- 중단 전에 다시 볼 위치나 다음 행동을 남기는 행동
- 중단했던 일을 다시 시작할 때 지금 다룰 목표와 범위를 한 가지로 좁히는 행동
- 자료 하나 열기처럼 바로 실행할 수 있는 작은 동작으로 재진입하는 행동
- 갑작스러운 중단, 예정된 전환, 휴식 뒤 복귀, 여러 과제 사이의 장면 차이

### 제외

- ADHD, 실행기능 장애, 우울·불안, 수면 문제의 선별 또는 진단
- 지능, 기억력, 집중력, 생산성, 성실성 또는 의지의 우열
- 미루는 이유나 숨은 동기
- 한 전략을 자주 사용하면 실제 수행이 반드시 좋아진다는 인과 주장
- 학생·직장인처럼 특정 역할만을 전제로 한 결과

### 인접 개념

과제 전환 비용, 주의 잔여, 목표 기억, 전망 기억, 인지 유연성 연구를 설계에
참고한다. 뉴앙의 세 차원은 실험실 과제의 수행 점수나 기존 임상·인지 검사의
번역 척도가 아니며 일상에서 관찰 가능한 다시 시작 방법을 별도로 구성한 것이다.

## 3. 독립 차원

| 차원                    | 행동 정의                                      | 높은 응답                                  | 낮은 응답                             | 금지 해석                 |
| ----------------------- | ---------------------------------------------- | ------------------------------------------ | ------------------------------------- | ------------------------- |
| 다시 시작할 지점 남기기 | 다시 볼 위치나 다음 행동을 짧게 남김           | 여러 전환 장면에서 재시작 단서를 자주 사용 | 최근에는 재시작 단서를 드물게 사용    | 기억력 부족, 산만함       |
| 지금 할 일 다시 잡기    | 다시 시작할 때 현재 목표·범위를 하나로 좁힘    | 목표 재정렬을 자주 사용                    | 최근에는 목표 재정렬을 드물게 사용    | 판단력·우선순위 능력 부족 |
| 작은 첫 행동 시작하기   | 집중 상태를 기다리지 않고 작은 동작으로 재진입 | 작은 진입 행동을 자주 사용                 | 최근에는 작은 진입 행동을 드물게 사용 | 실행력·의지 부족          |

세 차원은 서로 반대가 아니며 모두 높거나 낮을 수 있다. 독립 차원을 총점이나
집중 유형 하나로 합치지 않는다.

## 4. 공통 상황과 운영 문항

| 상황                                         | 다시 시작할 지점 남기기    | 지금 할 일 다시 잡기          | 작은 첫 행동 시작하기          |
| -------------------------------------------- | -------------------------- | ----------------------------- | ------------------------------ |
| 연락·요청으로 멈췄다가 다시 시작할 때        | 다음 할 일을 짧게 남김     | 지금 마칠 한 가지를 정함      | 바로 할 한 동작부터 시작       |
| 끝내지 못하고 다른 일을 한 뒤 다시 시작할 때 | 원래 일의 다음 지점을 표시 | 이번에 다룰 범위를 좁힘       | 자료 하나를 여는 동작부터 시작 |
| 쉬고 하던 일을 다시 시작할 때                | 돌아와 시작할 지점을 남김  | 지금 할 일을 한 문장으로 정리 | 2~5분짜리 첫 행동부터 시작     |
| 여러 일을 오가다 현재 위치가 헷갈릴 때       | 각 일의 현재 지점을 표시   | 먼저 이어갈 한 가지를 고름    | 확인·수정할 한 부분부터 시작   |

작성 규칙:

- 모든 문항은 최근 4주의 실제 행동 빈도를 묻는다.
- 한 문항에는 한 가지 전환 기능만 둔다.
- 역문항을 사용하지 않는다.
- 직장, 학업, 가사, 돌봄, 취미에 모두 적용 가능한 문장을 사용한다.
- 특정 앱·기기·문구·정리 도구를 반드시 사용하도록 요구하지 않는다.
- 판단 어려움 사유는 점수로 환산하지 않는다.

## 5. 채점

- 응답 척도: 거의 하지 않음, 드물게, 때때로, 자주, 거의 항상
- 표시 점수: 1~~5를 0~~100으로 선형 변환
- 공통 상황의 세 문항 중 하나라도 결측이면 그 상황 전체를 차원 비교에서 제외
- 차원당 최소 3개 완전 상황이 있을 때만 차원 점수 표시
- 차원별 평균·최솟값·최댓값·범위·변산성 저장
- 상황 범위가 50점 이상이면 장면 차이를 리포트에서 명시

## 6. 리포트와 주장 연결

리포트 순서:

1. 개인화된 핵심 요약
2. 세 행동별 점수와 빈도 해석
3. 집중이 끊긴 장면별 차이
4. 세 행동을 연결하는 방법
5. 다시 시작하는 방법이 오히려 부담이 되는 지점
6. 가까운 사람이 도울 수 있는 방법
7. 다음 10분의 복귀 순서
8. 개인 전략보다 방해 조건 조정이 먼저인 경우
9. 뉴앙 코드와 이번 결과의 교차 해석
10. 검사 설계 근거

주장 ID 범위:

## 7. 연구 근거 원장

| 연구                          | 설계 반영                               | 일반화 제한                                                        |
| ----------------------------- | --------------------------------------- | ------------------------------------------------------------------ |
| Leroy (2009)                  | 미완료 과제에서 남는 주의 잔여를 구분   | 직무 과제 실험이며 개인의 모든 생활 전환을 설명하지 않음           |
| Leroy & Glomb (2018)          | ready-to-resume 계획과 복귀 단서        | 시간 압박이 있는 업무 중단 연구이며 뉴앙 문항의 직접 타당화가 아님 |
| Altmann & Trafton (2002)      | 목표 재활성화와 단서의 기억 모형        | 이론 모형이며 자기보고 행동 빈도 척도가 아님                       |
| Trafton et al. (2003)         | 중단 직전 준비와 복귀                   | 통제된 인간-컴퓨터 과제이며 일상 성과를 보장하지 않음              |
| Monk et al. (2008)            | 방해 길이·요구도에 따른 복귀 차이       | 계층적 실험 과제 중심                                              |
| Dodhia & Dismukes (2009)      | 재개 의도와 전망 기억 단서              | 실험 과제의 재개 실패를 다루며 성향 유형 연구가 아님               |
| Masicampo & Baumeister (2011) | 구체적인 계획과 미완료 목표의 인지 간섭 | 목표 계획 연구이며 모든 중단 상황의 인과 효과를 보장하지 않음      |
| Monsell (2003)                | 과제 전환 비용과 준비 효과의 종합       | 단순 실험 과제 중심이며 일상 복귀 전략 척도가 아님                 |
| Egner & Siqi-Liu (2024)       | 인지 유연성을 맥락 적응 과정으로 해석   | 리뷰 논문이며 뉴앙 세 행동을 직접 검증하지 않음                    |

원문 DOI는 고객 결과의 `검사 설계 근거`와
`topic-assessment-evidence.ts`에서 관리한다.

## 10. 공개 후 운영

문항·도구 버전당 첫 30건 미만은 자동 수정하지 않는다. 이후 운영센터의 검사
품질 자동 검수에서 모호함, 경험 없음, 상황 의존, 반복 수정, 결과 불일치 신호를
확인한다. 기준은 상위 제작·운영 표준과 동일하게 적용한다.

운영 시스템은 수정 후보와 변경 비교를 만들 수 있지만 문항 의미, 채점 또는 공개
버전을 자동으로 바꾸지 않는다. 운영자가 변경 등급을 확인하고 새 버전을 승인한다.
