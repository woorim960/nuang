# 뉴앙 검사 품질·장문 리포트 개편 기준

## 목표

뉴앙의 검사 결과는 길어서 신뢰받는 것이 아니라, 문항에서 결과 문장까지
근거를 확인할 수 있어야 신뢰받는다. 2,000자 이상 리포트는 아래 조건을
충족하는 검사에만 제공한다.

1. 개인화 문장 하나마다 사용한 문항 묶음과 점수 구간을 추적할 수 있다.
2. 하나의 개인화 주장에 최소 3문항이 연결된다.
3. 상황을 설명하는 문장은 같은 상황을 묻는 2문항 이상이 있을 때만 쓴다.
4. 같은 내용을 제목만 바꿔 여러 섹션에서 반복하지 않는다.
5. 공통 교육 문장과 사용자의 답에서 나온 개인화 문장을 구분한다.
6. 안내·안전 문구는 2,000자 집계에서 제외한다.

## 근거 ID

| ID  | 의미                                             |
| --- | ------------------------------------------------ |
| E0  | 완료율, 판단 어려움, 동일 응답 반복 등 응답 품질 |
| E1  | 주 측정 영역 문항 묶음                           |
| E2  | 보조 측정 영역 문항 묶음                         |
| E3  | 같은 상황을 묻는 문항 묶음                       |
| E4  | 사전에 승인한 두 영역의 조합 규칙                |
| E5  | 다시 검사했을 때의 변화                          |
| E6  | 정밀 코어의 5축·10개 세부 점수                   |
| E7  | 친구 맞히기의 장면별 자기·예상·실제 선택         |
| E8  | 별난 연구소의 장면별 선택 분포                   |
| E9  | 전문가 검토를 마친 성향지도 지식 문장            |

## 검사별 공개 깊이

### 빠른 코어

- 22문항으로 다섯 방향을 빠르게 살펴보는 첫 결과다.
- 뉴앙 코드의 뜻, 점수 차이, 정밀 검사에서 더 확인할 내용을 보여준다.
- 가족·연인·업무 행동을 단정하는 장문 리포트와 공식 비교에는 쓰지 않는다.

### 정밀 코어

- 60문항과 필요한 축의 추가 문항을 사용한다.
- 5축, 10개 세부 점수, 상황별 답, 성향지도 지식을 조립한다.
- 결과 화면에서 2,000자 이상의 상세 미리보기를 제공하고 전체 성향지도로
  연결한다.
- 실제 출시 승격은 구조·신뢰도·재검사·공정성 검증을 통과한 측정 릴리스만
  가능하다.

### 주제 검사

- 관계·감정 주제는 최소 12문항, 생활 주제는 최소 9문항으로 보강한다.
- 현재 3문항 버전은 연구용으로 유지하며 고객 공개 카탈로그에서는 멈춘다.
- 보강 전에는 2,000자 결과를 생성하지 않는다.

### 별난 연구소

- 성향 진단이 아니라 생활 장면을 탐색하는 놀이로 운영한다.
- 장문 리포트를 제공하려면 9~12개 장면과 결과별 최소 3개 하위 묶음이
  필요하다.
- 코어 코드, 성향지도, 비교 결과는 바꾸지 않는다.

### 친구 성향 맞히기

- 현재 한 장면 버전은 관계 대화 게임이다.
- 2,000자 관계 리포트는 최소 6장면으로 확장한 뒤에만 제공한다.
- 궁합, 친밀도, 상대 코드 추정에는 사용하지 않는다.

## 장문 리포트 구조

1. 결과 한눈에 보기
2. 먼저 드러나는 모습
3. 상황별로 나타나는 행동
4. 그렇게 반응하는 이유
5. 잘 활용되는 점
6. 오해받기 쉬운 순간
7. 관계에서 활용하는 방법
8. 작은 시도
9. 결과의 선명도
10. 성향지도·커뮤니티·비교로 이어지는 다음 행동

## 구현 순서

1. 공개 상태와 측정 검증 상태를 분리한다.
2. 검사별 구성개념, 문항 묶음, 허용·금지 해석을 코드 계약으로 고정한다.
3. 주제·연구소·친구 검사 문항을 필요한 깊이까지 보강한다.
4. `claimId`, 근거 ID, 문항 ID, 점수 구간, 콘텐츠 버전을 가진 리포트
   문장 원장을 만든다.
5. 근거가 있는 섹션만 보여주는 결정형 리포트 조립기를 만든다.
6. 모든 검사 진행 화면을 공통 질문·응답·하단 도크 컴포넌트로 통일한다.
7. 320·360·390·430px, 키보드, 화면 읽기, 동작 줄이기를 검증한다.

## 2026-07-28 구현 현황

- 코어·주제·별난 연구소가 같은 질문 헤더, 연속 진행 막대, 응답 영역,
  하단 이전·다음 도크를 사용한다.
- 정밀 코어 결과는 32개 모든 뉴앙 코드에서 성향지도 근거 문장 2,000자
  이상을 제공한다.
- 정밀 결과에는 10개 세부 점수 중 이번 응답에서 가장 선명한 3개를 골라
  실제 점수와 쉬운 설명을 함께 보여준다.
- 빠른 코어에는 연인·가족·업무 장문 해석을 노출하지 않는다.
- 10개 주제검사는 모두 질문과 분리된 생활 장면 라벨을 사용한다.
- `지친 뒤 쉬는 방식`은 세 하위 영역을 각 3번 확인하는 9문항 구조로
  보강했다. 장문 결과 공개 전에는 문장 이해도와 응답 데이터 검증이
  추가로 필요하다.
- `사과 방식`은 세 하위 영역을 각 4번 확인하는 12문항으로 보강했다.
  27개 점수 방향 조합 모두에서 개인화 본문이 공백 제외 2,000자 이상이며,
  각 단락은 중복되지 않는 `claimId`를 가진다. 문장 이해도·신뢰도·구조
  검증을 통과하기 전까지 운영 공개는 멈춘다.
- `위로받을 때 필요한 것`은 동일한 네 장면에서 서로 반대가 아닌 세
  도움(마음을 알아주는 도움·방법을 함께 찾는 도움·내 속도와 선택)을
  모두 묻는 4×3 행렬형 12문항으로 개편했다. 도움마다 문항 상황이 달라
  생기던 비교 오류를 줄이고, 겪지 않은 장면은 중간값으로 넣지 않는다.
  한 영역에서 3개 이상의 유효 답이 있을 때만 점수를 보여준다.
- 도움별 평균뿐 아니라 문항별 환산점수, 최솟값·최댓값·범위·분산을
  보존한다. 같은 50점이라도 네 장면이 모두 50점인 경우와
  0·0·100·100점인 경우를 각각 `steady`와 `varied`로 나누어 다른
  문장으로 설명한다.
- 위로 리포트는 5개 답변 의미 구간, 개인화된 위로 순서, 장면별 차이,
  가까운 사람에게 보여줄 한 문장, 관계별 활용, 계산 방법을 제공한다.
  낮은 점수를 반대 도움에 대한 선호로 바꾸지 않으며 공감 능력·애착·
  의존성·정신건강·관계 성공을 추론하지 않는다.
- 위로 검사의 문항·채점·리포트 버전은 각각
  `comfort-style-v2-common-scenes-2026-07-28`,
  `comfort-style-scoring-v3-pattern-aware`,
  `comfort-style-report-v3-personalized`로 고정한다. 이전 문항 결과를
  새 리포트로 재해석하지 않는다.
- 나머지 7개 주제검사는 현재 3문항 연구 버전이므로 고객 카탈로그에서
  공개하지 않는다.
- 별난 연구소는 진단이 아닌 선택 놀이로만 공개하며, 짧은 결과가
  뉴앙 코드나 비교 결과를 바꾸지 않는다.
- 주제 검사 서버는 브라우저가 보낸 점수와 해석을 신뢰하지 않는다.
  공식 문항을 모두 답했는지 확인한 뒤 서버에서 역채점과 점수 계산을
  다시 수행하며, 공식 검사명·분류·결과만 저장한다.
- 서버 저장 결과에는 문항 원장 버전과 `server-v2-missing-aware` 채점
  버전을 함께 기록해, 겪지 않은 장면을 중간값으로 넣던 과거 결과와
  구분할 수 있게 했다.
- 주제 검사 결과는 로딩·결과 없음·오류를 구분하고, 320px에서도 공통
  헤더·응답 묶음·하단 도크·스크롤 가능한 안내 시트를 사용한다.
