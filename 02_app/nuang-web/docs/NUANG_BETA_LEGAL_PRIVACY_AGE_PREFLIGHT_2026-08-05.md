## 3. 만 14세 미만 무료 후보 흐름

시행령이 명시한 무료 구현 후보는 전자우편 회신 또는 서명한 서면 제출이다. 자동 링크 클릭만으로 승인하지 않는다.

1. 가입 첫 단계에서 `만 14세 이상`과 `만 14세 미만`을 분리한다.
2. 만 14세 미만이면 계정과 OAuth 세션을 만들지 않고, 법정대리인의 성명과 연락처만 동의 요청 목적으로 받는다.
3. 법정대리인에게 개인정보 수집·이용 목적, 항목, 보유기간, 거부권과 불이익, 아동과의 관계 확인 문구를 포함한 동의 전문을 이메일로 보낸다.
4. 법정대리인이 같은 주소에서 명시적인 동의 의사표시를 적어 회신하도록 한다. 단순 링크 클릭, 열람 픽셀, 아동이 입력한 일회용 코드만으로는 승인하지 않는다.
5. 운영자가 발신 주소, 필수 문구, 아동 참조값, 관계 진술, 정책 버전을 수동 확인한다. 승인 전 상태는 `guardian_review_pending`으로 두고 모든 계정 저장 기능을 차단한다.
6. 승인 기록에는 아동 계정 참조, 보호자 연락처의 최소 식별값, 동의 문서 버전, 요청·회신·검토 시각, 검토 담당자와 증빙 참조만 남긴다. 이메일 원문과 불필요한 신분 자료는 서비스 DB에 복사하지 않는다.
7. 거부·기한 만료·확인 실패 시 계정을 만들지 않고 동의 요청용 보호자 정보를 지체 없이 삭제한다.
8. 승인 후에도 법정대리인의 열람·정정·삭제·처리정지·동의 철회 경로를 제공한다.

### 엄격한 판정

- **단순 이메일 클릭:** 충분하다고 볼 수 없다. 시행령 제17조의2 제5호는 동의 내용을 적은 이메일 발송과 법정대리인의 동의 의사표시가 적힌 이메일 회신을 명시한다.
- **무료 가능성:** 명시적 이메일 회신과 수동 검토는 외부 인증 API 비용 없이 설계할 수 있다.
- **남은 불확실성:** 이메일 발신자가 실제 법정대리인인지, 만 14세 이상 자기확인을 어느 수준으로 검증할지는 무료 방식만으로 강한 신원 보증을 제공하기 어렵다. 변호사가 이 위험과 운영 증빙을 승인하기 전에는 만 14세 미만 가입을 구현·공개하지 않는다.

## 5. AI 사전검토와 변호사 승인 상태 모델

하나의 `approved` 값으로 합치지 않는다.

### AI 사전검토

- `not_started`: 코드·정책 대조 전
- `issues_found`: 공식 근거와 코드 사이의 쟁점이 남음
- `ready_for_counsel`: 쟁점, 증빙, 코드 버전을 변호사에게 전달할 준비 완료

AI 상태는 베타 내부의 최소 정책·코드 대조 게이트를 완료할 수 있다. 다만 외부 법률
검토 게이트를 승인하거나 변호사 승인으로 승격할 수 없다.

### 변호사 검토

- `not_requested`: 변호사 전달 전
- `in_review`: 특정 정책 버전과 Git commit 검토 중
- `changes_requested`: 수정·재검토 필요
- `approved`: 담당 변호사, 승인 시각, 승인 증빙 참조와 대상 버전이 모두 기록됨

### 외부 법률 검토 게이트

- `blocked`: 외부 검토를 요청했지만 필수 쟁점이 해결되지 않은 상태다.
- `counsel_approved`: 모든 필수 항목의 변호사 승인과 운영 설정 대조가 완료됨
- `superseded`: 정책·코드·처리업체·연령 흐름 변경으로 이전 승인 무효

관리자 화면은 AI 쟁점과 변호사 판단을 별도 패널로 보여주고, 변호사 승인 기록에 담당 변호사·법무법인, 정책 버전, Git commit, 증빙 참조, 승인 시각을 필수로 요구한다. 정책 문구, 처리업체, 국외 리전, 연령 흐름, 유료 기능 중 하나가 바뀌면 자동으로 `blocked`로 돌아가야 한다.

## 6. 베타 내부 게이트 완료 근거와 재검토 조건

### 완료 근거

1. 만 14세 이상 자기확인은 화면·요청·OAuth callback·DB RPC에서 fail-closed로 적용한다.
2. 만 14세 미만 계정과 계정 기반 커뮤니티 저장은 열지 않고, 비회원 일반 검사만 기기 로컬에 저장한다.
3. `adult_verification_required` 콘텐츠는 공개 목록과 직접 주소 모두에서 차단한다.
4. 필수·선택 동의, 현재 분석 동의 버전, 철회, 결과·계정 삭제와 재가입 회귀 테스트를 통과했다.
5. 개인정보 처리 인벤토리와 공급자·OAuth 실제 운영 증빙을 대조했고, 운영 DB readiness와 보유기간 migration을 확인했다.
6. 운영센터는 AI 내부 사전대조와 외부 법률 승인을 별도 상태로 표시한다.

### 외부 법률 검토를 다시 여는 조건

다음 중 가장 이른 시점 전에 외부 법률 검토를 재개한다.

1. 유료 결제·구독·재화 또는 용역의 청약을 시작할 때
2. 예시가 아닌 실제 광고를 본운영할 때
3. 법정대리인 동의 흐름을 구현해 만 14세 미만 가입을 열 때
4. 제한 베타를 넘어 정식 공개 범위를 확대할 때

재검토 전까지 주소 비공개 무료 베타, 만 14세 미만 가입, 19세 전용 콘텐츠와
유료 기능의 현재 잠금을 유지한다.
