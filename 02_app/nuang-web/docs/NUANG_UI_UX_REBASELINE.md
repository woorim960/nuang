# NUANG UI/UX Rebaseline

작성일: 2026-07-11 KST

이 문서는 NUANG MVP의 전반 UI/UX를 홈 중심으로 다시 정렬하기 위한 기준선이다. 목표는 단순히 화면을 예쁘게 바꾸는 것이 아니라, 사용자가 매일 들어와도 부담 없이 머물고 신뢰를 잃지 않게 만드는 것이다.

## 방향

- 홈은 메뉴판이나 일반 피드 대시보드가 아니라 검사를 중심으로 뉴앙의 핵심 가치를 시작하는 곳이다.
- 피드는 작성보다 읽기, 반응, 저장, 코드별 공감으로 체류를 만든다.
- 검사는 별도 하단 메뉴가 아니라 홈의 주인공이며, 나와 서로를 알아가는 콘텐츠 라이브러리다.
- 성향지도는 개인 그래프가 아니라 32개 코드 세계를 둘러보는 탐색 공간이다.
- 마이는 데이터 관리 화면이 아니라 내 코드, 리포트, 설정을 안정적으로 다시 여는 개인 공간이다.

## 첫 화면 원칙

첫 화면은 아래 순서로 구성한다.

1. `나를 이해하고, 서로를 이해하는 성향 놀이터`라는 정체성을 말한다.
2. 검사 시작·이어하기·결과 보기 중 하나를 제안한다.
3. 추천, 나 알아보기, 함께하기, 연구소로 콘텐츠를 탐색하게 한다.
4. 생활 주제 검사와 함께하기를 통해 재방문할 이유를 제공한다.
5. 커뮤니티는 별도 하단 메뉴에서 온전한 체류 흐름을 제공한다.

## UI 원칙

- 페이지 섹션은 얇은 선과 full-width band를 중심으로 구성한다.
- 반복 항목, 모달, 도구 표면에만 카드 형태를 쓴다.
- 둥근 장식, 과한 그림자, 큰 그라데이션은 최소화한다.
- 캐릭터 이미지는 감정적 초점으로 쓰되 화면마다 하나의 역할만 맡긴다.
- 버튼은 명령, 링크는 이동, 스위치는 설정이라는 역할을 섞지 않는다.
- 긴 설명보다 짧은 제목, 보조 문장, 명확한 다음 행동을 우선한다.
- 트렌디함은 색보다 리듬, 여백, 타이포, 반응 가능한 밀도에서 만든다.

## 검사 중심 홈 기준

홈은 다음 구조를 기준으로 한다.

- `브랜드 약속`: 유일한 h1으로 슬로건을 보여준다.
- `상태별 핵심 경험`: 진행 중 정밀 검사, 진행 중 첫 검사, 정밀 결과, 첫 결과, 신규 시작 순으로 다음 행동 하나를 제안한다.
- `추천`: 공개 주제 검사, 함께하기, 연구소, 보조 기능 순으로 보여준다.
- `나 알아보기`: 생활 주제 검사를 탐색한다.
- `함께하기`: 밸런스 게임과 친구 성향 맞히기를 시작한다.
- `연구소`: 가볍고 뜻밖의 성향 콘텐츠를 탐색한다.
- 카테고리는 `/home`, `/home?view=self`, `/home?view=together`, `/home?view=lab`과 동기화한다.
- 홈에는 커뮤니티 피드 preview나 실제 광고 슬롯을 넣지 않는다.

## 체류 루프

사용자의 하루 루프는 아래 흐름을 목표로 한다.

```text
홈에서 상태별 검사 추천 확인
→ 검사 또는 리포트 열기
→ 생활 주제 검사 또는 함께하기 탐색
→ 결과를 마이에서 다시 확인
→ 커뮤니티에서 다른 사람의 생각과 만나기
→ 다음 방문 때 새 검사 또는 이어갈 행동 추천
```

## 다음 개편 순서

1. 피드: 읽기 밀도, 반응 affordance, 저장한 글 회수 흐름 개선
2. 마이: 내 코드 요약, 내 리포트, 공개 범위, 데이터 권리의 정보 계층 정리
3. 홈: 코어, 무료 주제, 함께하기, 연구소 콘텐츠의 추천 품질 개선
4. 성향지도: 32개 코드 탐색과 내 코드 연결의 리듬 개선
5. 공통 UI: 버튼, 섹션, 리스트, empty state, privacy note 패턴 통일
