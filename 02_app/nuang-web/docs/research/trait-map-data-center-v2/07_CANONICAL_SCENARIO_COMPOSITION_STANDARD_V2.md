# 상황 문장 canonical 합성 기준 v2

## 목적

같은 뉴앙 코드의 문장이 어떤 부모 원장에서 파생됐는지에 따라 달라지는 문제를
없앤다. 최종 문장은 오직 승인된 의미 축과 해당 코드의 알파벳 조합으로만
결정한다.

## 합성 단위

상황 72개마다 다음 네 채널을 별도로 다룬다.

1. 무엇을 먼저 살피는지
2. 처음 드는 생각
3. 실제 나타나는 반응
4. 어떻게 말하는지

전체 합성 단위는 `72 × 4 = 288개`다.

## 한 슬롯의 순서

1. 모든 원문 변형과 사용 코드를 모은다.
2. 문장을 공통 상황 핵심, 단일축 방향, 복합축, 안전 경계 의미 단위로
   나눈다.
3. 각 의미 단위를 유지, 쉬운 한국어 수정, 중복 제외, 근거 부족 제외 중
   하나로 기록한다.
4. 승인된 축이 `n개`라면 `2ⁿ개` 알파벳 조합을 빠짐없이 만든다.
5. 각 조합 문장에 사용한 의미 단위, 원문 변형, 근거 결과, 독립 자료를
   연결한다.
6. 제외한 내용도 삭제하지 않고 제외 이유를 계보에 남긴다.
7. 7개 전문 검토와 고위험 독립 근거 기준을 통과한 뒤에만 원장 재생성을
   허용한다.

## 경로 독립성

예를 들어 한 슬롯의 확정 축이 `SE·RO`라면 가능한 문장은 다음 네 개다.

- `SE=E|RO=G`
- `SE=E|RO=A`
- `SE=I|RO=G`
- `SE=I|RO=A`

`ENAKQ`가 ENAKQ 원장에서 직접 왔는지, 다른 코드를 여러 번 변환해
도달했는지는 문장 선택에 영향을 주지 않는다. 코드의 첫째 글자와 셋째
글자가 같으면 언제나 같은 canonical 문장을 선택한다.

## 승인 차단 조건

- 축 조합 하나라도 누락
- 서로 다른 조합이 완전히 같은 문장
- 원문 변형 하나라도 유지·병합·수정·제외 기록 누락
- 유지하기로 한 의미 단위가 최종 문장에서 누락
- 처음 드는 생각·실제 나타나는 반응을 본인 전용 외로 공개
- 관계 결과·정신건강·능력·업무 고위험 문장에 독립 근거 2개 미만
- 성격심리·심리측정·관계심리·임상안전·쉬운 한국어·제품·디자인 검토 미완료

## 현재 상태

이 계약은 합성 방법만 고정했다. 288개 축 분류와 의미 단위 검토는 아직
`research_only`이며, 승인 전에는 32개 성향 원장과 고객 화면을 재생성하지
않는다.
