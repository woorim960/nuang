# 뉴앙 코드 32개 별칭 체계 V2

> 릴리스: `NUANG-PROFILE-NAME-CANDIDATE-2.1`
> 상태: 제품 반영 후보 · 이름 이해도 검증 필요
> 기준: 짧고 기억하기 쉬움 · 코드에서 뜻을 거슬러 올라갈 수 있음 · 32개가 서로 구분됨 · 우열과 낙인을 만들지 않음

## 1. 별칭은 두 단계로 보여 준다

뉴앙 코드는 `ENAKQ · 관계를 여는 지휘자`처럼 **코드와 긴 별칭**을 먼저 보여 준다. 공유 카드나 작은 프로필에서는 `ENAKQ · 지휘자`처럼 **짧은 별칭**을 사용할 수 있다.

- 짧은 별칭: 한눈에 기억하고 대화할 때 사용한다.
- 긴 별칭: 짧은 별칭만으로 놓칠 수 있는 성향 방향을 보충한다.
- 뉴앙 코드 설명: 정확한 의미가 궁금할 때 각 글자의 결과와 비율을 함께 확인한다.

별칭은 직업, 능력, 등급이 아니다. 긴 성향 설명을 기억하기 쉽게 묶은 활동명이다. 이 안내는 결과 화면에서 한 번만 명확하게 제공하고, 모든 문단에서 반복하지 않는다.

## 8. 자동 감사 기준

1. 정확히 32개 코드가 있어야 한다.
2. 짧은 별칭 32개와 긴 별칭 32개는 각각 중복되지 않아야 한다.
3. 짧은 별칭은 3~6글자여야 한다.
4. 긴 별칭은 `관계를 여는 지휘자`와 비슷한 호흡을 유지하도록 네 어절을 넘지 않아야 한다.
5. 모든 코드는 정확히 하나의 성향군에 속하고, 각 성향군에는 8개 코드가 있어야 한다.
6. `천재`, `완벽`, `우월`, `치유`, `정상`, `문제형`처럼 능력·건강·가치를 단정하는 말은 사용하지 않는다.
7. 각 긴 별칭은 해당 코드의 연구 원장과 반대되는 행동을 암시해서는 안 된다.
8. 실제 사용자에게는 별칭과 함께 뉴앙 코드별 비율을 제공한다. 별칭만으로 정밀한 개인차를 대신하지 않는다.

### 2.1 재검토에서 바꾼 이름

- `ERGKQ`: “문제를 빠르게 푼다”는 능력 단정을 피하고, Q가 뜻하는 빠른
  반응을 살려 **변수에 빠르게 반응하는 해결사**로 바꿨다.
- `IRGKQ`: Q를 위험 예측 능력으로 오해하지 않도록 **변수를 꼼꼼히 살피는
  전략가**로 바꿨다.
- `IRGMQ`: M과 어긋날 수 있는 “끝까지”를 빼고 **변화의 원인을 좇는
  추적자**로 바꿨다.
- `INGKQ`: 검사하지 않는 미래 예측 능력을 암시하는 “예측가”를 빼고
  **가능성과 변수를 살피는 구상가**로 바꿨다.

나머지 28개는 현재 단계에서 유지한다. 다만 32개 모두 실제 사용자의
5초 이해도·하루 뒤 회상·공유 의향 검증 전에는 제품 후보 이름이다.

## 9. 사람 검증에서 확인할 질문

- 이름을 보고 5초 안에 어떤 사람인지 한 문장으로 말할 수 있는가?
- 짧은 별칭과 긴 별칭 중 하나를 하루 뒤에도 기억하는가?
- 한 글자만 다른 코드 두 개의 이름을 보고 차이를 납득할 수 있는가?
- 이름이 능력, 직업, 성별, 나이, 정신건강의 평가처럼 들리지 않는가?
- 자신의 코드 이름을 프로필이나 공유 카드에 표시하고 싶은가?
- 이름보다 더 잘 맞는 일상 표현을 사용자가 자발적으로 제안하는가?

이름 이해도 검증에서 특정 별칭의 오해가 반복되면 코드나 연구 원장을 바꾸지 않고 해당 별칭만 교체한다. 이름 만족도와 측정 타당도는 서로 다른 검증 항목으로 관리한다.
