# v2.3 성향 문구 인지 면담 프로토콜

## 목적

고객이 문장을 별도 설명 없이 의도한 축·상황·처음 생각·실제 반응으로
이해하는지 확인한다. 인지 면담은 이해 가능성을 다루며 점수 타당도나
검사 신뢰도를 대신하지 않는다.

## 공식 방법 근거

- [교육·심리검사 표준](https://www.testingstandards.net/): 의도한
  해석과 사용에 맞는 타당성 근거와 문서화
- [ITC 검사 번역·적응 지침](https://www.intestcom.org/files/guideline_test_adaptation_2ed.pdf):
  직역이 아닌 기능적·문화적 동등성과 질적·경험적 확인
- [COSMIN 매뉴얼 v2](https://www.cosmin.nl/wp-content/uploads/COSMIN-manual-V2_final.pdf):
  대상 표본의 인지 면담, 이해 가능성 평가, 수정 후 최종 형태 재시험

## 참여자 정보

이름·이메일·전화번호는 받지 않는다. 서버가 만든 익명
`participantRef`와 통계에 필요한 나이대·한국어 편안함·읽기 배경·
성향검사 친숙도만 필수로 받는다. 성별 범주는 후속 집단별 문항 기능
연구에 동의한 경우에만 선택으로 받으며 개인 결과에는 사용하지 않는다.

## 진행 순서

1. 조용히 읽고 읽는 시간을 기록한다.
2. 떠오른 뜻을 순서대로 말한다.
3. 자신의 말로 바꾸어 설명한다.
4. 먼저 보는 것·처음 생각·실제 반응의 예를 든다.
5. 더 가까운 코드 방향과 이유를 고른다.
6. 어렵거나 번역투로 느낀 표현을 표시한다.
7. 능력·도덕성·진단·관계 성공을 단정한다고 읽히는지 확인한다.
8. 반대 방향 문장과의 차이를 설명한다.

## 표본과 판정

- P0 162개 → P1 131개 claim 그룹 → P2 층화 표본 54개 순서
- 한 회기 12~16개, 일반 문구 2명 이상, 고위험 문구 3명 이상 노출
- 첫 반복은 서로 다른 배경의 7~10명으로 시작하고 새 오해가 계속 나오면
  추가
- 두 코더가 독립 판정하고 불일치는 제3 검토자와 합의
- 작은 표본의 백분율만으로 통과시키지 않으며 오해 유형·반복·심각도와
  수정 후 재시험을 함께 확인

현재 프로토콜만 준비됐고 참여자 수집은 시작하지 않았다. 모든 문장은
계속 research_only다.
