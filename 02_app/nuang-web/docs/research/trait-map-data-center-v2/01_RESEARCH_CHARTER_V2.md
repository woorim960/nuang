# 뉴앙 성향지도 연구 헌장 v2

- 헌장 ID: `NUANG-TRAIT-MAP-RESEARCH-CHARTER.v2`
- 기준일: `2026-07-23`
- 상태: `FOUNDATION_LOCKED`

## 1. 연구 목표

뉴앙의 32개 역할형 성향마다 사용자가 자신과 궁금한 사람의 성향을 구체적으로
이해할 수 있는 연구 데이터센터를 구축한다.

각 역할형 패키지는 다음 질문에 답할 수 있어야 한다.

- 어떤 가치를 중요하게 여기는가
- 무엇에 먼저 관심이 가는가
- 어떤 생각이 먼저 떠오르는가
- 실제로는 어떤 반응이 나타나는가
- 평소 선택과 행동이 어떻게 이어지는가
- 가족·친구·연인·마음 가는 사람·업무 관계에서 무엇이 달라지는가
- 갈등·변화·불확실성·부담 속에서 어떻게 반응하고 회복하는가
- 어떤 점이 강점으로 작용하고, 과해질 때 어떤 마찰이 생기는가
- 다른 성향과 왜 비슷해 보이며 어디에서 갈리는가
- 서로를 더 잘 이해하려면 어떤 말을 주고받는 것이 좋은가

## 2. 연구 결과가 사용되는 제품

동일한 승인 데이터를 다음 화면에서 목적에 맞는 길이로 재사용한다.

| 화면 | 사용하는 정보 |
| --- | --- |
| 정밀 검사 결과 | 사용자가 가장 궁금해할 핵심·관계·생활 요약 |
| 내 성향 상세 | 축·facet 점수와 연결된 개인화 설명 |
| 성향지도 상세 | 역할형 전체 장문과 상황별 탐색 |
| 나와 비교하기 | 두 사람에게 모두 승인된 공통점·차이·대화 안내 |
| 공개 프로필 | 공개 안전 범위의 짧은 설명 |
| 커뮤니티 | 사용자가 공개한 코드와 승인된 탐색 정보 |
| 근거 페이지 | 연구 출처·검증 방법·버전 |

화면마다 따로 문장을 작성하지 않는다. 한 의미는 하나의 canonical claim과
content atom으로 관리한다.

## 3. 연구 단위

### 3.1 공통 지식층

- 대표 축 5개: `SE · OE · RO · SM · ER`
- 고객 코드 5자리: `E/I · R/N · G/A · K/M · C/Q`
- 세부 성향 10개:
  `SE-RE · SE-AI · OE-AE · OE-CI · OE-IE · RO-EC · SM-EP · SM-OS · ER-IR · ER-WD`

### 3.2 조합 지식층

- 한 글자 경향
- 두 글자 상호작용
- 세 글자 상호작용
- 다섯 글자 역할형 전체 경향
- 한 글자만 다른 인접 역할형 비교

외부 연구가 뉴앙의 다섯 글자 조합을 직접 검증했다고 표현하지 않는다.
외부 연구는 축·facet·상황·행동 연결의 근거로 사용하고, 역할형 조합은
뉴앙 문항·점수·사용자 자료에서 별도로 확인한다.

## 4. 설명의 기본 문법

고객 문장은 다음 순서로 쓴다.

```text
중요하게 여기는 것
→ 먼저 관심이 가는 것
→ 처음 드는 생각
→ 실제 나타나는 반응
→ 상대가 볼 수 있는 행동
→ 잘 통하는 대화 방법
```

좋은 예:

> 관계에서 상대의 마음 상태가 먼저 눈에 들어오는 편이에요. 그래서 가까운
> 사람이 힘들다고 말하면 해결책을 바로 꺼내기보다, 무엇이 가장 힘들었는지
> 먼저 묻는 반응이 자주 나타나요.

피할 예:

> 상황에 따라 그럴 수도 있고 아닐 수도 있어요.

연구상의 불확실성은 모든 고객 문장에 반복하지 않고 근거 상태·노출 조건·근거
페이지에서 관리한다. 고객 문장은 검증된 범위 안에서 경향을 분명하게 설명한다.

## 5. 사용하지 않는 추론

다음 내용은 별도 검사를 만들지 않는 한 5자리 코드에서 직접 추정하지 않는다.

- 정신질환, 애착유형, 소시오패스·사이코패스 여부
- 공감 능력, 지능, 창의력, 리더십, 책임감, 도덕성
- 특정 직업에서의 성과
- 상대의 호감, 사랑의 크기, 관계 성공 가능성
- 회복력, 정신건강, 감정조절 능력
- 게시물·사진·활동 기록만으로 추정한 성향

성향과 관련이 보고된 외부 결과가 있더라도 뉴앙이 해당 변수를 직접 측정하지
않았다면 개인 결과로 단정하지 않는다.

## 6. 근거의 역할

근거는 세 가지 층으로 분리한다.

1. `외부 근거`: 성격·상황·관계·업무·감정 연구에서 확인된 결과
2. `뉴앙 측정 근거`: 문항이 목표 축과 facet을 측정한다는 자료
3. `뉴앙 콘텐츠 근거`: 해당 claim과 고객 문구가 이해되고 재현된다는 자료

세 층 중 하나라도 빠진 역할형 고유 문장은 연구용으로 유지한다.

- 공백 제외 50,000~60,000자 장문

- 근거 원장
- claim registry
- 중복·모순 감사
- 전문 검토 원응답과 조정 기록
- 사용자 인지검사 결과
- 정량 검증 결과
- 고객용 짧은·표준·장문 콘텐츠
- 발행 릴리스와 변경 이력

수량은 최소 완성 조건이지 품질을 대신하는 점수가 아니다.

## 8. 전문 검토

| 역할 | 주요 질문 |
| --- | --- |
| 성격심리 | 성향 이론과 행동 설명이 맞는가 |
| 심리측정 | 실제 측정 범위를 넘어가지 않는가 |
| 관계심리 | 관계 맥락과 상호작용을 한 사람 코드로 단정하지 않는가 |
| 임상안전 | 낙인·진단·위험한 조언이 없는가 |
| 쉬운 한국어 | 남녀노소가 한 번에 이해할 수 있는가 |
| 제품기획 | 고객의 실제 궁금증을 해결하는가 |
| 디자인 | 모바일에서 많은 정보를 편하게 찾을 수 있는가 |

검토 판정은 `accept · revise · reject · insufficient_evidence` 네 가지로
기록한다. 다수결로 밀어붙이지 않고 근거와 위험을 확인해 조정한다.

## 9. 발행 게이트

1. `F0 계약`: 데이터 구조와 연구 목적 고정
2. `F1 근거`: 검색·선별·추출·매핑 완료
3. `F2 원문`: 5만 자·16개 장·claim 원장 완료
4. `F3 전문 검토`: 7개 역할별 필수 검토 통과
5. `F4 인지 검토`: 실제 사용자의 이해·회상·판단·표현 확인
6. `F5 정량 검증`: 문항·점수·claim 연결과 재현 확인
7. `F6 제품 검증`: 중복·개인정보·노출 조건·모바일 사용성 확인
8. `F7 발행`: 승인 content atom만 제품 릴리스에 포함

앞 단계가 통과되지 않으면 다음 상태를 `approved` 또는 `published`로
바꾸지 않는다.
