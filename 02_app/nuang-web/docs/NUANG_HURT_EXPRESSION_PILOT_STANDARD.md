# 뉴앙 서운함 표현 검사 파일럿 기준

## 고객이 확인하는 질문

- 고객용 이름: `서운할 때 나는 어떻게 말할까?`
- 내부 슬러그: `hurt-expression`
- 목적: 최근 서운했던 상황에서 실제로 나타난 세 가지 말하기 행동을
  각각 돌아본다.
- 공개 단계: 자기이해용 파일럿

이 검사는 표현 능력, 정서지능, 공격성, 애착유형, 관계의 건강함을
판정하지 않는다. 상대가 실제로 잘못했는지나 관계가 회복될 가능성도
측정하지 않는다.

## 선정 이유

심리학, 심리측정, 일반 고객 관점에서 다음 후보를 비교했다.

- 서운함 표현
- 갈등 후 회복
- 대화 시작
- 거리감
- 충전 루틴
- 집중 전환
- 정리 방식
- 기분 전환
- 좋아하는 마음 표현

`서운함 표현`은 구성개념을 실제 행동으로 분리하기 쉽고, 위로 검사와
사과 검사를 보완하며, 가족·친구·연인·학교·팀·업무에 활용할 수 있어
이번 순서의 검사로 정했다. 고객 호기심과 공유 가치가 높은
`좋아하는 마음 표현`은 다음 후보로 보존한다.

## 측정 구조

네 가지 공통 상황에서 세 행동을 한 번씩 묻는 `4 × 3 = 12문항`
구조다.

### 공통 상황

1. 가까운 사람이 약속을 갑자기 바꾸거나 잊었을 때
2. 대화 중 내 말이나 의견이 가볍게 넘어갔다고 느꼈을 때
3. 모임·학교·팀에서 나만 중요한 내용을 늦게 알았을 때
4. 이미 서운하다고 말한 일이 다시 반복됐을 때

### 세 행동

- 무엇이 서운했는지 말하기: 마음에 걸린 말·행동·상황을 구체적으로
  말했는가
- 내 마음 말하기: 그 일로 내가 어떤 마음이 들었는지 말했는가
- 바라는 점 부탁하기: 다음에 원하는 행동을 조정 가능한 부탁으로
  말했는가

세 행동은 서로 반대가 아니므로 모두 높거나 낮을 수 있다. 첫 행동은
사건의 구체화, 두 번째는 감정의 언어화, 세 번째는 변화 요청으로
구분한다.

## 응답과 결측

최근 6개월 실제 행동을 기준으로 답한다.

1. 거의 하지 않았어요
2. 드물게 했어요
3. 때때로 했어요
4. 자주 했어요
5. 거의 항상 했어요

응답은 `0 / 25 / 50 / 75 / 100`점으로 환산한다.

- 비슷한 일이 한 번뿐이면 그때 실제로 한 말을 기준으로 답한다.
- 상대와 말할 기회가 없거나 안전하게 말하기 어려웠다면 답하기 어려움을
  선택할 수 있다.
- 한 장면의 세 문항 중 하나라도 유효한 답이 없으면 그 장면 전체를
  세 행동 비교에서 제외한다.
- 완전하게 답한 장면이 3개 미만이면 상세 점수를 제공하지 않는다.
- 결측을 중간값으로 바꾸지 않는다.
- 세 행동을 합친 총점이나 대표 행동은 만들지 않는다.

## 결과 해석

각 행동은 다섯 구간으로 표시한다.

- 0~12: 거의 하지 않았어요
- 13~37: 드물게 했어요
- 38~62: 때때로 했어요
- 63~87: 자주 했어요
- 88~100: 거의 항상 했어요

세 점수 차이가 12점 이내이면 비슷한 정도로 해석한다. 모두 낮음,
모두 중간, 모두 높음, 공동 최고·공동 최저를 별도로 처리하며 배열상
한 행동을 임의로 고르지 않는다. 점수 크기로 실제 말의 순서를 추정하지
않는다.

## 결과 리포트

1. 이번 결과 한눈에 보기
2. 세 행동별 점수·수준·장면 차이
3. 세 행동을 함께 활용하는 방법
4. 가까운 사람에게 써볼 한 문장
5. 가족·친구·연인·학교·팀·업무 적용 예시
6. 말이 잘 전해지지 않을 때 확인할 점
7. 다음에 써볼 한마디
8. 검사 당시 뉴앙 코드로 보는 표현 방법
9. 직접 대화보다 안전이 우선인 상황

리포트는 125개 점수 조합마다 2,000자 이상을 제공한다. 같은 문장을
대상 이름만 바꾸어 반복하지 않고, 각 관계에서 실제로 활용할 수 있는
다른 정보를 제공한다.

## 해석 금지

- 점수가 높음 = 건강한 소통 또는 표현 능력이 좋음
- 점수가 낮음 = 무관심, 회피, 감정이 없음
- 직접 말하기 = 모든 상황에서 더 좋은 선택
- 부탁하기 = 상대가 받아들여야 하는 요구
- 세 행동의 빈도 = 실제 대화의 시간 순서
- 뉴앙 코드 = 세 점수의 원인

## 안전 기준

상대가 위협하거나 통제하거나 보복할 가능성이 있다면 직접 표현을
권하지 않는다. 믿을 수 있는 사람, 보호자, 학교·직장의 공식 절차를 먼저
이용할 수 있도록 안내한다. 결과가 상대에게 사과, 변화, 대화, 관계 유지를
요구할 근거가 되지 않도록 한다.

## 공통 구현 계약

새로운 검사별 UI를 만들지 않는다.

- 목록: `AssessmentHub`
- 문항 진행: `FreeTopicRunner`
- 문항·응답·팝업: `AssessmentQuestionControls`
- 결과: `FreeTopicResultView`
- 공유: `ReportShareSheet`
- 저장·동기화: `free-topic-storage`, `/api/free-topic-results`
- 프로필 공개: 같은 원본 결과 리포트의 읽기 전용 모드

검사별로 달라지는 것은 문항, 채점 버전, 리포트 데이터, 공유 문구뿐이다.

## 자동 검증

- 12문항과 4개 공통 장면
- 척도별 문항 4개
- `5 × 5 × 5 = 125개` 조합
- 모두 낮음·중간·높음
- 공동 최고·공동 최저
- 완전 장면 3개와 4개
- 뉴앙 코드 32개
- 리포트 2,000자 이상
- claim ID 중복 없음
- 결과 주인의 검사 당시 코드·원본 리포트 보존
- 본인·공유 링크·프로필에서 같은 원본 리포트 사용

## 공개 상태

현재 내부 상태는 `pilot + published`다. 고객 화면에 개발 중이라는 문구를
노출하지 않지만, 검증 완료·진단·정확한 능력 평가라고 표현하지 않는다.

`released`로 승격하려면 전문가 내용타당도, 다양한 연령의 문장 이해도,
실제 응답의 3요인 구조, 척도 신뢰도, 천장·바닥 효과, 재검사, 연령·성별
문항 편향을 확인해야 한다.
