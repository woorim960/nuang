# 뉴앙 사과 방식 검사 파일럿 기준

## 고객이 확인하는 질문

- 고객용 이름: `사과할 때 나는 어떻게 풀어갈까?`
- 내부 슬러그: `apology-style`
- 목적: 최근 미안했던 상황에서 실제로 나타난 세 행동을 각각 돌아본다.
- 공개 단계: 자기이해용 파일럿

이 검사는 사과 능력, 진정성, 인격, 관계의 미래를 판정하지 않는다.
누가 더 좋은 사람인지 비교하는 총점도 만들지 않는다.

## 전문가 합의

심리학, 성향검사 설계, 일반 고객 관점의 독립 검토를 거쳐 다음 원칙을
확정했다.

1. 의도나 마음을 추측하지 않고 실제로 한 행동을 묻는다.
2. 세 행동은 서로 반대가 아니므로 각각 점수를 낸다.
3. 행동의 빈도로 실제 대화에서의 순서를 추정하지 않는다.
4. 한 장면의 세 답 중 하나라도 없으면 그 장면 전체를 비교에서 제외한다.
5. 모두 높음·모두 낮음·동점을 별도 해석하고, 동점 중 하나를 임의로
   대표 행동으로 고르지 않는다.
6. 뉴앙 코드는 점수를 바꾸지 않고 결과를 실제 말로 옮길 때 참고하는
   표현 정보로만 사용한다.
7. 결과 주인의 검사 당시 뉴앙 코드와 리포트를 원본 스냅샷으로 보관한다.

## 측정 구조

네 가지 공통 상황에서 세 행동을 한 번씩 묻는 `4 × 3 = 12문항`
구조다.

### 공통 상황

1. 약속 시간이나 연락을 놓쳤을 때
2. 내 말이나 행동으로 가까운 사람이 상처받았을 때
3. 학교·팀·업무에서 내 몫을 제대로 하지 못했을 때
4. 같은 문제로 다시 미안한 일이 생겼을 때

### 세 행동

- 내가 놓친 점 인정하기: 내가 하지 못했거나 상처가 된 사실을 구체적으로
  말했는가
- 상대의 마음 듣기: 내 설명 전에 상대가 겪은 불편이나 상처를 들었는가
- 다음 행동 정하기: 바로잡을 일과 다음에 바꿀 행동을 구체적으로
  정했는가

## 응답 척도

질문:

> 비슷한 상황에서 나는 얼마나 자주 이렇게 행동했나요?

선택지:

1. 거의 하지 않았어요
2. 드물게 했어요
3. 때때로 했어요
4. 자주 했어요
5. 거의 항상 했어요

응답은 `0 / 25 / 50 / 75 / 100`점으로 환산한다. 세 행동의 평균이나
사과 총점은 제공하지 않는다.

## 답하기 어려운 상황

- 비슷한 경험이 거의 없음
- 상황마다 많이 다름
- 문장이 이해되지 않음
- 답하고 싶지 않음

비슷한 일이 한 번뿐이었다면 그때 실제로 한 행동을 기준으로 답한다.
상황을 겪지 않았거나 상대와 대화할 기회가 없었다면 답하기 어려움을
선택한다.

한 장면의 세 문항 중 하나라도 유효한 답이 없으면 그 장면 전체를 세
행동 비교에서 제외한다. 완전하게 답한 장면이 3개 미만이면 상세 해석을
제공하지 않는다. 결측을 중간값으로 바꾸지 않는다.

## 결과 리포트 구조

1. 이번 결과 한눈에 보기
2. 세 행동의 점수와 상황별 차이
3. 세 행동을 함께 활용하는 방법
4. 가까운 사람에게 써볼 한 문장
5. 가족·친구·연인·학교·팀·업무 적용 예시
6. 사과가 어긋날 때 확인할 점
7. 다음에 써볼 한마디
8. 검사 당시 뉴앙 코드로 보는 표현 방법
9. 책임의 범위와 안전 기준

### 해석 금지

- 점수가 높음 = 사과를 잘함 또는 진심이 큼
- 점수가 낮음 = 상대를 중요하게 여기지 않음
- 다음 행동을 정함 = 실제로 행동을 완료함
- 세 행동의 빈도 = 실제 대화에서 먼저 한 행동의 순서
- 뉴앙 코드 = 세 점수의 원인

## 자동 검증 범위

- `5 × 5 × 5 = 125개` 점수 조합
- 세 행동 모두 낮음·중간·높음
- 최고·최저 동점
- 상황별 동점
- 완전한 장면 3개와 4개
- 뉴앙 코드 32개
- 본인 리포트와 상대가 보는 공개 원본 리포트
- 리포트 2,000자 이상
- 중복 claim ID 없음

## 공통 구현 계약

검사별 화면을 새로 만들지 않는다.

- 목록: `AssessmentHub`
- 문항 진행: `FreeTopicRunner`
- 문항·응답·판단 어려움·종료 팝업: `AssessmentQuestionControls`
- 결과: `FreeTopicResultView`
- 공유: `ReportShareSheet`
- 저장·동기화: `free-topic-storage`, `/api/free-topic-results`
- 프로필 공개 결과: 같은 원본 리포트의 읽기 전용 모드

검사별로 달라지는 것은 문항 데이터, 채점 계약, 결과 문장, 공유 내용뿐이다.

## 공개와 검증

현재 단계는 `파일럿`이다. 고객에게는 자기이해용 검사로 제공할 수 있지만
검증 완료, 진단, 정확한 능력 평가라는 표현은 사용하지 않는다.

공식 검사로 승격하려면 다음을 확인한다.

1. 일반 고객이 문항을 같은 뜻으로 이해하는지
2. 심리학 전문가가 세 행동의 내용 범위를 충분하다고 판단하는지
3. 실제 응답에서 세 요인 구조가 구분되는지
4. 각 척도의 신뢰도와 천장·바닥 효과가 적절한지
5. 재검사 결과와 문항별 연령·성별 편향이 허용 범위인지
