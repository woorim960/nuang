# 뉴앙 운영센터 V2

## 목표

운영자가 모바일 앱 화면을 해석하는 대신, 해야 할 업무와 상태를 한눈에 파악하고 안전하게 처리할 수 있는 데스크톱 우선 운영 도구를 제공한다. 모바일에서는 같은 기능을 핵심 정보 중심의 카드와 전체 화면 편집 흐름으로 바꿔 제공한다.

## 정보 구조

### 서비스 운영

- 운영 개요: 처리 대기 업무, 핵심 지표, 이벤트 상태, 최근 관리자 활동
- 회원 관리: 회원 검색, 상태 필터, 공개 프로필·계정 상태 확인, 정지·복구
- 커뮤니티: 신고, 게시물, 밸런스게임, 오늘의 질문
- 이벤트: 응모 현황, 추첨, 당첨자 연락

### 품질 관리

- 검사 연구: 문항별 위험 신호와 검토 우선순위
- 성향 콘텐츠: 성향지도 릴리스와 전문 검토

### 운영 설정

- 운영 기록: 관리자 조치 검색, 세부 정보, CSV
- 시스템 상태: 환경 설정과 데이터베이스 연결 상태

## 공통 UX 원칙

- 데스크톱 작업 영역은 최대 1480px를 사용한다.
- 페이지에서 가장 중요한 작업 하나만 강조한다.
- 목록은 큰 카드 묶음보다 행과 구분선을 사용한다.
- 브랜드 보라는 현재 위치와 주요 작업에만 사용한다.
- 성공·주의·위험은 각각 초록·주황·빨강의 의미색으로 구분한다.
- 삭제, 정지, 게시처럼 영향이 큰 작업은 대상과 결과를 설명하는 전용 확인창을 사용한다.
- 모든 저장 작업은 중복 클릭을 막고 성공·실패 결과를 즉시 보여준다.
- 모바일에서는 8개 메뉴를 가로 스크롤하지 않고 현재 메뉴에서 전체 메뉴를 펼쳐 선택한다.

## 공식 커뮤니티 콘텐츠

### 관리 대상

- 밸런스게임
- 오늘의 질문

### 운영 상태

`초안 → 예약 → 게시 중 → 종료 → 보관`

발행 실패는 별도 상태로 남겨 재시도할 수 있어야 한다.

### 핵심 운영 기능

- 등록·수정
- 실제 피드 형태 미리보기
- 즉시 게시·예약 게시
- 종료
- 기존 콘텐츠 복제
- 게시 위치 선택: 홈, 커뮤니티
- 게시 후 참여 수 확인
- 모든 변경의 관리자·시각·변경 전후 기록

### 안전 규칙

- 질문은 4~160자다.
- 밸런스게임은 서로 다른 선택지 2개가 필수다.
- 게시 시작 시각은 종료 시각보다 빨라야 한다.
- 첫 투표나 답변 이후 질문 의미와 선택지는 직접 변경하지 않는다.
- 수정이 필요하면 복제해 새 버전으로 게시한다.
- 홈의 같은 시간대에는 같은 유형의 공식 콘텐츠를 하나만 게시한다.
- 게시·종료·예약 취소는 전용 확인창에서 영향 범위를 확인한다.

## 후속 기능 메모

### P1

- 회원·신고·게시물의 서버 페이지네이션과 복합 필터
- 커뮤니티 콘텐츠 캘린더
- 노출 수, 참여율, 코드별 선택 분포, 댓글·공유·저장 통계
- 운영 기록의 기간·관리자·업무·결과 필터와 변경 전후 비교
- 예약 게시 실패 작업과 재시도
- 연구 문항의 담당자, 검토 메모, 승인·보류
- 성향 콘텐츠의 버전 비교와 수정 요청 사유

### P2

- 운영 역할 분리: 최고 관리자, 커뮤니티 운영자, 검토자, 편집자, 게시자, 연구자, 읽기 전용
- 반복 일정
- 질문 A/B 테스트
- 추천 게시 시간
- 자동 품질 경고
- 다중 운영자 승인

## 반응형 기준

- 1280px 이상: 고정 사이드바와 넓은 행·표 중심 작업 영역
- 900~1279px: 사이드바와 축약된 열
- 768~899px: 현재 메뉴 중심의 모바일 내비게이션, 핵심 열만 노출
- 767px 이하: 목록은 카드형 행, 편집은 전체 화면, 주요 저장 작업은 접근하기 쉬운 하단 영역

모든 터치 대상은 최소 44px이며, 가로 스크롤 없이 주요 업무를 완료할 수 있어야 한다.
