# 뉴앙 광고·제휴 MVP 운영 및 화면 설계안

- 문서 상태: **뉴앙 베타 범위 승인 · 단계 구현 중**
- 작성일: 2026-08-05
- 승인일: 2026-08-05
- 적용 범위: 광고주 삽입 배너, 쿠팡 파트너스
- 이번 단계: 관리자 운영 안내 → 자체 제작 예시 배너 노출 → 실제 광고 송출 기반 → 테스트 → 운영 준비

> 이 문서는 광고 운영 경험이 없는 사람도 문의 접수부터 송출 종료까지 혼자 처리할 수 있게 만드는 기준서다. 뉴앙 베타에서는 실제 광고와 성과 집계에 포함되지 않는 자체 제작 예시 배너를 홈에 먼저 노출하고, 실제 광고 송출은 소재·정책·일정 승인을 모두 통과한 캠페인만 허용한다.

승인되면 기존 `NUANG_ADVERTISING_PLATFORM_V1_PRODUCT_SPEC.md`의 상품 조합 가운데 AdSense 관련 MVP 범위는 이 문서가 대체한다. 기존 문서의 광고 금지 화면, 개인정보 보호, 빈도 제한, 긴급 중지 원칙은 계속 유지한다.

---

## 1. 먼저 결정할 내용

아래 6개 항목을 기본안으로 제안한다. 문서 전체를 검토하기 어렵다면 이 표부터 확인하면 된다.

| 결정             | 권장안                                 | 이유                                                                                                |
| ---------------- | -------------------------------------- | --------------------------------------------------------------------------------------------------- |
| MVP 광고 유형    | **광고주 배너 + 쿠팡 파트너스만 운영** | 요청 범위와 일치하며 운영 복잡도를 줄인다. 기존 AdSense는 보류한다.                                 |
| 광고주 배너 위치 | **홈 추천 화면 1곳**                   | 사용자가 핵심 콘텐츠를 먼저 본 뒤 자연스럽게 노출할 수 있다.                                        |
| 쿠팡 위치        | **커뮤니티 추천 게시물 8개 뒤**        | 현재 구현 위치를 유지하고 유기 콘텐츠를 먼저 보장한다.                                              |
| 광고 판매 방식   | **7일 단위 고정 기간 판매**            | MVP에서 CPM 과금·부정 클릭 정산을 만들지 않아도 된다. 금액은 캠페인별로 수동 확정한다.              |
| 소재 전달 방식   | **계약 뒤 전용 업로드 링크 발급**      | 공개 문의 폼에 파일을 받아 스팸·악성 파일 위험을 키우지 않는다.                                     |
| 실제 앱 미리보기 | **관리자 전용 실제 경로 미리보기**     | 운영 앱과 같은 컴포넌트와 레이아웃을 사용하면서 일반 사용자에게 샘플 광고가 노출되는 오해를 막는다. |

### 승인하면 바뀌는 것

1. `/admin/advertising` 상단에 누구나 따라 할 수 있는 7단계 운영 가이드가 생긴다.
2. 광고주 문의를 캠페인·소재·계약·결제·송출 일정과 연결해 관리할 수 있다.
3. 광고주가 안전한 전용 링크에서 배너 파일을 제출할 수 있다.
4. 관리자 화면에서 모바일·데스크톱 미리보기를 확인할 수 있다.
5. `실제 화면에서 보기`를 누르면 홈 또는 커뮤니티의 진짜 화면 구성 안에서 광고를 검수할 수 있다.
6. 승인된 광고주 배너는 홈에, 쿠팡 카드는 커뮤니티에만 노출된다.
7. 노출·조회 가능 노출·외부 이동·숨김·신고·정산 금액을 캠페인별로 확인할 수 있다.

### 승인해도 자동으로 일어나지 않는 것

- 광고가 즉시 운영 사용자에게 공개되지 않는다.
- 문의자에게 자동으로 견적이나 계약서가 발송되지 않는다.
- 결제가 자동 처리되지 않는다.
- 쿠팡 상품이 성향 정보에 따라 개인화되지 않는다.
- 향후 광고 유형이 함께 개발되지 않는다.

## 2. 현재 구현 점검 결과

### 2.1 이미 구현된 기능

- 공개 광고 안내 `/advertise`
- 3단계 광고·제휴 문의 `/advertise/inquiry`
- 문의 접수번호, 운영자 알림 메일, 재시도 대기열
- 관리자 문의 상태·우선순위·다음 조치일 관리
- 캠페인 초안·정책 검수·예약·송출 상태 관리
- 쿠팡 소재 URL·이미지 URL·문구·목적지 검수
- 슬롯별 노출 비율·빈도 제한·긴급 중지
- 홈 AdSense 슬롯과 커뮤니티 쿠팡 카드 코드
- 노출·외부 이동·숨김·광고 의견 이벤트

### 2.2 요청과 맞지 않거나 빠진 기능

| 항목             | 현재 상태                                                 | 필요한 개선                                                 |
| ---------------- | --------------------------------------------------------- | ----------------------------------------------------------- |
| 직접 광고주 배너 | 관리자 선택지는 있으나 승인·예약·송출이 명시적으로 차단됨 | 직접 배너 전용 송출·검수·성과 집계 구현                     |
| 광고주 소재 제출 | 외부 이미지 URL만 입력 가능                               | 계약 뒤 만료되는 안전한 파일 업로드 링크 제공               |
| 미리보기         | 업로드 이미지와 텍스트만 별도로 표시                      | 실제 홈·커뮤니티 컴포넌트와 동일한 모바일·데스크톱 미리보기 |
| 운영 가이드      | 탭과 상태 용어만 있고 전체 업무 흐름 설명 부족            | 다음 행동과 완료 조건을 화면마다 안내                       |
| 상품 구성        | 기존 기획은 AdSense + 쿠팡 중심                           | MVP를 직접 배너 + 쿠팡으로 재편                             |
| 계약·결제        | 자유 메모만 존재                                          | 금액·부가세·입금·세금계산서·계약 증빙 상태 구조화           |
| 소재 규격        | 이미지 주소 외 크기·용량·권리 확인 없음                   | 파일 규격 자동 검사와 권리·표현·목적지 체크리스트           |
| 실화면 샘플      | 운영 조건이 없으면 아무것도 보이지 않음                   | 관리자 전용 샘플 캠페인과 실제 경로 미리보기                |
| 중복 예약        | 같은 위치·시간대 충돌을 명확히 막지 않음                  | 슬롯별 캠페인 기간 중복 차단                                |

### 2.3 결론

기존 기반은 버릴 필요가 없지만, 직접 배너를 운영 상품으로 열기 위한 별도 설계와 데이터 변경이 필요하다. 단순히 관리자 화면에 설명과 이미지만 추가하면 실제 접수·검수·송출이 연결되지 않으므로 이 문서 승인 뒤 한 흐름으로 구현한다.

## 3. 두 광고 유형의 차이

관리자 화면 상단에 아래 내용을 그대로 요약해 보여준다.

### 3.1 광고주 삽입 광고 배너

| 질문                     | 답변                                             |
| ------------------------ | ------------------------------------------------ |
| 누가 요청하나?           | 외부 광고주 또는 대행사                          |
| 뉴앙은 무엇을 제공하나?  | 합의한 기간 동안 홈의 지정 위치에 배너 노출      |
| 광고주는 무엇을 주나?    | 배너 이미지, 브랜드명, 이동 주소, 광고 내용 증빙 |
| 뉴앙은 어떻게 돈을 받나? | MVP에서는 7일 단위 고정 금액, 선입금 원칙        |
| 무엇을 보고하나?         | 노출, 조회 가능 노출, 외부 이동, 숨김·신고 수    |
| 개인 성향을 쓰나?        | 사용하지 않음                                    |
| 누가 최종 승인하나?      | 운영 담당자 + 정책 검토자                        |

### 3.2 쿠팡 파트너스

| 질문                  | 답변                                                                            |
| --------------------- | ------------------------------------------------------------------------------- |
| 광고주 문의가 오나?   | 아니요. 뉴앙이 쿠팡 파트너스에서 직접 링크를 만든다.                            |
| 뉴앙은 무엇을 올리나? | 쿠팡에서 사용을 허용한 링크와 이미지로 만든 제휴 카드                           |
| 수익은 어떻게 생기나? | 이용자가 링크로 이동해 인정되는 구매를 하면 쿠팡 기준에 따라 수수료가 발생한다. |
| 무엇을 보고하나?      | 뉴앙의 노출·외부 이동 수와 쿠팡 포털의 확정 수익을 별도로 대조한다.             |
| 개인 성향을 쓰나?     | 사용하지 않음. 화면 맥락과 운영자의 수동 선정만 사용한다.                       |
| 누가 최종 승인하나?   | 운영 담당자 + 정책 검토자                                                       |

두 유형 모두 화면에 `광고` 또는 `광고 · 쿠팡 파트너스`를 텍스트로 명확하게 표시한다. 색상만으로 광고임을 구분하지 않는다.

## 4. 광고가 실제로 보이는 위치

### 4.1 광고주 배너 — 홈 추천

기존 홈의 콘텐츠 순서를 유지하고 한 곳에만 둔다.

```text
NUANG 홈 헤더
서비스 소개
생활 속 나를 알아보기 — 주제검사 3개
[ 광고주 삽입 배너 HOME_INLINE_01 ]
함께하면 더 재밌어요
연구소·기타 콘텐츠
하단 내비게이션
```

노출 원칙:

- 첫 화면의 핵심 CTA보다 앞에 놓지 않는다.
- 홈 추천 탭에서만 노출한다.
- 한 번에 배너 1개만 노출한다.
- 같은 슬롯에 기간이 겹치는 두 캠페인을 예약할 수 없다.
- 로그인 여부나 성향 결과로 배너를 바꾸지 않는다.
- 운영자와 14~18세 사용자에게는 실제 광고를 노출하지 않는 현재 보호 정책을 유지한다.

### 4.2 쿠팡 파트너스 — 커뮤니티 추천

```text
커뮤니티 헤더·필터
글쓰기
공개·검수 통과 게시물 1~8
[ 쿠팡 파트너스 카드 FEED_COMMERCE_01 ]
공개 게시물 9부터 계속
하단 내비게이션
```

노출 원칙:

- 추천 피드에서 공개 게시물이 8개 이상일 때만 노출한다.
- 성향 필터 사용 중, 특정 게시물 강조 상태, 다른 커뮤니티 모드에서는 노출하지 않는다.
- 가격·할인율·배송처럼 자주 바뀌는 정보는 카드 설명에 직접 적지 않는다.
- 쿠팡 포털에서 확인한 공식 링크와 사용 가능한 소재만 사용한다.

### 4.3 광고 금지 화면

- 모든 검사 문항 화면
- 모든 검사 결과·리포트 화면
- 밸런스 게임 메인·방 설정·선택·결과 화면
- 관계 비교 화면
- 로그인·회원가입·동의 화면
- 마이 화면
- 운영센터
- 개인정보·법률·안전 관련 화면

이 목록은 광고 매출보다 우선하는 고정 보호 규칙으로 둔다.

## 5. 실제 앱과 같은 광고 UI

### 5.1 광고주 배너 구성

```text
┌──────────────────────────────────┐
│ 광고                  광고 의견 │
│                                  │
│ [광고주가 제출한 3:1 배너 이미지] │
│                                  │
│ 광고주명              자세히 보기 │
└──────────────────────────────────┘
```

- 앱의 현재 콘텐츠 너비와 좌우 여백을 그대로 사용한다.
- 카드처럼 과도한 그림자나 장식 아이콘을 붙이지 않는다.
- 이미지 전체가 이동 링크이며 새 창으로 연다.
- `rel="sponsored nofollow noopener noreferrer"`를 적용한다.
- 배너 위에 뉴앙 자체 CTA나 캐릭터를 겹치지 않는다.
- 광고주가 제출한 이미지가 없어도 운영 화면에서 임의 이미지를 대신 공개하지 않는다.
- 광고 의견 메뉴에서 `관심 없어요`, `너무 자주 보여요`, `불편한 내용이에요`, `잘못된 광고 같아요`를 제공한다.

### 5.2 직접 배너 파일 규격

MVP에서는 기기별 파일을 따로 받지 않고 하나의 비율을 사용한다.

| 항목        | 규격                                                     |
| ----------- | -------------------------------------------------------- |
| 권장 크기   | 1440 × 480px                                             |
| 비율        | 정확히 3:1                                               |
| 형식        | JPG, PNG, WebP                                           |
| 최대 용량   | 2MB                                                      |
| 금지        | GIF, SVG, 동영상, 투명 배경만 있는 이미지                |
| 안전 여백   | 좌우 72px, 상하 48px 안쪽에 핵심 문구 배치               |
| 텍스트      | 모바일에서 읽을 수 있는 크기, 과장·깜빡임·가짜 버튼 금지 |
| 대체 텍스트 | 관리자가 80자 이내로 작성·검수                           |

업로드 때 픽셀 크기·비율·용량·파일 서명을 자동 검사한다. 확장자만 바꾼 파일은 거절한다. 원본은 비공개 저장소에 보관하고 검수 뒤 웹용 변환본만 공개 저장소에 게시한다.

### 5.3 쿠팡 카드 구성

현재 앱의 쿠팡 카드 구조를 유지하되 실제 미리보기와 운영 안내를 보강한다.

```text
┌──────────────────────────────────┐
│ 광고 · 쿠팡 파트너스    광고 의견 │
│ 필수 대가성 안내 문구              │
│ [공식 이미지]  제목               │
│               짧은 설명      ↗    │
└──────────────────────────────────┘
```

- 상품 이미지는 정사각형으로 보인다.
- 제목은 최대 2줄, 설명은 최대 2줄로 제한한다.
- 이미지·링크 사용 조건과 대가성 문구는 등록 시점의 쿠팡 파트너스 포털 정책을 최종 기준으로 한다.
- 미리보기용 샘플은 자체 제작한 `샘플 상품` 이미지를 사용하며 쿠팡 공식 상품처럼 보이게 만들지 않는다.

### 5.4 로딩과 성능

- 승인된 소재가 있을 때만 공간을 예약해 빈 광고 테두리를 남기지 않는다.
- 이미지 크기를 미리 알고 `aspect-ratio`를 고정해 화면 밀림을 막는다.
- 이미지 변환본은 WebP/AVIF를 우선 제공하고 화면 너비에 맞는 `srcset`을 사용한다.
- 화면 아래 광고는 지연 로딩한다.
- p75 CLS 0.1 이하, 광고 도입 증가분 0.02 이하를 목표로 한다.
- 광고 조회 가능 노출은 화면에 50% 이상이 1초 동안 보일 때 기록한다.

## 6. 광고주 문의부터 종료까지

### 6.1 전체 흐름

```text
1. 광고주 문의 접수
2. 운영자가 적합성·일정 확인
3. 상품·기간·금액 제안
4. 계약·입금 확인
5. 광고주에게 소재 업로드 링크 발급
6. 자동 파일 검사 + 사람 검수
7. 모바일·데스크톱·실제 앱 화면 확인
8. 캠페인 예약
9. 5% → 25% → 50% → 100% 단계적 송출
10. 종료·성과 리포트·정산 기록
```

### 6.2 문의 접수

현재 공개 문의 흐름은 유지하되 MVP 상품을 명확히 한다.

- 문의 유형 첫 항목을 `홈 배너 광고`로 표시한다.
- `쿠팡 파트너스`는 외부 광고주가 신청하는 상품이 아니므로 문의 선택지에 넣지 않는다.
- 브랜드 함께하기 등 향후 상품은 `향후 제휴 아이디어`로 분리하고 즉시 판매 상품처럼 보이지 않게 한다.
- 접수 뒤 `영업일 기준 1~2일 안에 연락` 안내와 접수번호를 보여준다.
- 운영자는 회사명, 목표, 희망 일정, 예산, 이동 페이지, 소재 준비 상태를 한 화면에서 본다.

### 6.3 첫 검토

운영 화면에 다음 체크리스트를 제공한다.

- [ ] 서비스와 관련성이 있는 브랜드인지 확인
- [ ] 금지 업종 또는 고위험 업종이 아닌지 확인
- [ ] 이동 페이지가 HTTPS이고 실제 광고주가 관리하는 주소인지 확인
- [ ] 희망 기간에 홈 배너 슬롯이 비어 있는지 확인
- [ ] 예산과 7일 단위 판매 방식이 맞는지 확인
- [ ] 광고주의 소재 준비 여부 확인
- [ ] 담당자에게 첫 답변을 보냈는지 확인

하나라도 확인하지 못했으면 다음 단계로 넘어가지 않고 `다음 조치`에 날짜와 할 일을 기록한다.

### 6.4 제안·계약·입금

MVP 판매 기준:

- 7일 단위 고정 기간 판매
- 한 기간에 홈 배너 1개
- 금액은 운영자가 캠페인별로 입력하며 가격표 공개는 별도 승인 뒤 진행
- 선입금 확인 뒤 소재 업로드 링크 발급
- CPM·CPC 보장 또는 구매 전환 보장 없음
- 노출 오류가 합의한 기준을 넘으면 기간 연장 방식으로 보전

관리 항목:

- 공급가액
- 부가세
- 총액
- 계약 상태
- 계약서 또는 발주서 참조번호
- 입금 상태와 입금 확인일
- 세금계산서 발행 상태
- 광고주 리포트 수신 이메일
- 취소·보전 메모

계약 파일 자체는 MVP에서 운영 DB에 무리하게 저장하지 않고, 승인된 회사 문서 저장소의 참조 링크와 문서번호만 기록하는 방식을 기본안으로 한다.

### 6.5 소재 업로드

광고주에게 계정을 만들게 하지 않는다.

1. 운영자가 계약된 문의에서 `소재 요청 링크 만들기`를 누른다.
2. 7일 동안 유효한 일회성 링크가 생성된다.
3. 광고주는 브랜드명, 배너 파일, 이동 URL, 이미지 내 주요 문구, 권리 확인을 제출한다.
4. 서버가 파일 크기·비율·형식·악성 파일 여부를 검사한다.
5. 제출되면 기존 링크은 닫히고 운영자에게 알림이 간다.
6. 수정 요청이 생기면 새 버전 링크를 발급한다.

광고주 업로드 화면에 다음 내용을 친절하게 안내한다.

- 실제 화면에서 보이는 위치
- 3:1 예시 프레임
- 파일 크기와 허용 형식
- 작은 화면에서도 글자가 읽혀야 한다는 안내
- 가짜 닫기 버튼·알림창·과장 표현 금지
- 제출 뒤 운영 검수와 수정 요청이 있을 수 있다는 안내
- 최종 승인 전에는 광고가 공개되지 않는다는 안내

### 6.6 소재 검수

승인 버튼 위에 아래 항목을 모두 배치한다.

- [ ] 광고임이 명확하게 표시됨
- [ ] 브랜드명과 실제 광고주가 일치함
- [ ] 이미지 사용 권한을 확인함
- [ ] 모바일 320·360·390px에서 잘리지 않음
- [ ] 데스크톱에서 빈 공간이나 확대 깨짐이 없음
- [ ] 목적지 URL과 표시 도메인이 일치함
- [ ] 거짓·과장·오인 표현이 없음
- [ ] 가격·혜택·기간 주장에 근거 또는 만료일이 있음
- [ ] 금지 업종·연령 제한·민감 주제가 아님
- [ ] 계약·입금 상태가 완료됨
- [ ] 실제 홈 화면 미리보기를 확인함

검수자는 `승인`, `수정 요청`, `거절` 중 하나와 사유를 남긴다. 최종 승인은 검수자 계정과 시각을 운영 기록에 저장한다.

### 6.7 예약·송출

- 승인 소재, 정책 승인, 입금 완료, 비어 있는 슬롯, 시작·종료일이 모두 있어야 예약 가능하다.
- 시작일 전에는 `예약`, 기간 중에는 `송출 중`, 종료 시각 뒤에는 `종료`가 된다.
- 첫 캠페인은 5%부터 열고 문제가 없을 때 25% → 50% → 100%로 올린다.
- 긴급 중지는 전역, 광고 유형, 슬롯, 캠페인 단위로 제공한다.
- 중지와 재활성화에는 반드시 사유를 입력한다.

### 6.8 리포트·종료

광고주 리포트:

- 집행 기간
- 광고 노출 수
- 조회 가능 노출 수
- 외부 이동 수
- 외부 이동률
- 숨김 수
- 불편 신고 수
- 중지 시간과 보전 여부

개별 사용자, 성향 코드, 검사 결과, 게시물 열람 이력은 제공하지 않는다. 수치가 적어 개인을 추정할 위험이 있으면 기간 전체 합계만 제공한다.

## 7. 쿠팡 파트너스 운영 방법

쿠팡은 광고주 문의가 아니라 내부 운영 업무로 안내한다.

### 7.1 운영 순서

1. 쿠팡 파트너스 포털에서 뉴앙 서비스 URL 등록 상태를 확인한다.
2. 서비스의 일반적인 맥락에 맞는 상품 또는 카테고리를 운영자가 고른다.
3. 공식 제휴 링크와 사용 가능한 이미지를 만든다.
4. `/admin/advertising`에서 쿠팡 캠페인을 만든다.
5. 소재 제목·설명·이미지·이동 주소·대가성 문구를 등록한다.
6. 실제 커뮤니티 화면에서 카드와 링크를 확인한다.
7. 정책 검수 후 예약·송출한다.
8. 월별로 뉴앙 집계와 쿠팡 포털의 확정 수익을 대조한다.

### 7.2 상품 선정 기준

- 특정 성향 코드에 맞춘 추천을 하지 않는다.
- 검사 결과나 관계 결과를 근거로 상품 필요성을 단정하지 않는다.
- `커뮤니티에서 함께 이야기할 수 있는 일반 생활 주제` 범위에서 수동 선정한다.
- 가격, 할인율, 로켓배송 여부처럼 바뀌는 수치를 설명에 고정하지 않는다.
- 건강·의료·금융 효능을 암시하는 상품은 MVP에서 제외한다.
- 링크·이미지·고지 문구는 등록할 때마다 쿠팡 포털 정책을 다시 확인한다.

### 7.3 정산

- 뉴앙의 외부 이동 수와 쿠팡의 주문·확정 수익은 같은 지표가 아니다.
- 관리자 성과 화면에서 `뉴앙 외부 이동`과 `쿠팡 확정 수익`을 분리한다.
- 쿠팡 확정 수익은 월 단위로 운영자가 입력하고 근거가 된 정산월을 기록한다.
- 사용자별 구매 여부를 뉴앙으로 가져오지 않는다.

## 8. 관리자 광고·제휴 화면 개편

### 8.1 상단 고정 안내

페이지를 열면 가장 먼저 아래 두 영역이 보인다.

1. **광고 유형 이해하기**
   - 광고주 배너와 쿠팡 파트너스의 차이를 두 개의 간단한 카드로 설명
   - `광고주에게 받는 것`, `뉴앙이 하는 일`, `수익 방식`, `노출 위치` 표시
2. **지금 해야 할 일**
   - 예: `2건의 문의에 답변이 필요해요`, `1개 소재가 실제 화면 검수를 기다려요`
   - 버튼을 누르면 해당 항목으로 바로 이동

### 8.2 운영 7단계 가이드

화면 상단에 진행 단계를 항상 표시한다.

| 단계            | 운영자가 하는 일                 | 완료 조건                     |
| --------------- | -------------------------------- | ----------------------------- |
| 1 문의 확인     | 새 문의를 읽고 담당자를 정함     | 첫 답변과 다음 조치일 기록    |
| 2 제안          | 위치·기간·금액을 합의함          | 제안 전달 상태와 제안일 기록  |
| 3 계약·입금     | 계약과 입금을 확인함             | 계약·입금 상태 완료           |
| 4 소재 받기     | 전용 링크를 보내고 파일을 받음   | 자동 파일 검사 통과           |
| 5 검수·미리보기 | 문구·권리·목적지·실화면을 확인함 | 모든 체크리스트와 검수자 승인 |
| 6 예약·송출     | 기간과 노출 비율을 설정함        | 안전 조건 충족 후 예약/송출   |
| 7 리포트·종료   | 성과와 정산을 정리함             | 종료 리포트와 보전 여부 기록  |

각 단계에는 `왜 필요한가`, `무엇을 확인하나`, `완료하면 무엇이 되나`를 접어서 볼 수 있는 설명으로 제공한다.

### 8.3 탭 구성

| 탭            | 역할                                                |
| ------------- | --------------------------------------------------- |
| 운영 가이드   | 처음 운영하는 사람이 두 상품과 전체 절차를 이해함   |
| 문의          | 신규 문의, 응답 기한, 담당자, 다음 행동 관리        |
| 캠페인        | 광고 유형, 기간, 계약·입금, 상태 관리               |
| 소재·미리보기 | 파일 버전, 검수 체크리스트, 기기별/실제 앱 미리보기 |
| 노출 위치     | 홈·커뮤니티 위치와 빈도·송출 비율 관리              |
| 성과·정산     | 캠페인 성과, 광고주 리포트, 쿠팡 확정 수익 관리     |
| 설정          | 환경 준비, 허용 도메인, 긴급 중지 관리              |

기존의 전문 용어 `인벤토리`는 화면 제목에서 `노출 위치`로 바꾸고 도움말에서만 내부 용어로 설명한다.

### 8.4 모든 화면에 들어갈 공통 안내

- 이 화면에서 할 수 있는 일
- 가장 먼저 확인할 항목
- 다음 단계로 넘어가는 조건
- 최종 승인하면 실제로 무엇이 바뀌는지
- 되돌릴 수 있는 방법과 긴급 중지 위치
- 잘못 입력했을 때 누구에게 어떤 정보를 전달해야 하는지

## 9. 실제 앱 미리보기 설계

### 9.1 원칙

관리자 전용으로 따로 그린 비슷한 카드가 아니라, 실제 앱에 쓰는 광고 컴포넌트를 그대로 사용한다.

- 광고주 배너: `DirectSponsoredBanner`
- 쿠팡 카드: 기존 `CoupangAffiliateCard`를 미리보기 가능 구조로 분리
- 홈·커뮤니티 실제 경로도 같은 컴포넌트를 사용
- 미리보기에서는 성과 이벤트와 빈도 제한을 기록하지 않음
- 샘플에는 `샘플 광고 · 실제 캠페인 아님`을 표시

### 9.2 관리자 내부 미리보기

`소재·미리보기` 탭에 아래 조작을 제공한다.

- 광고 유형: 광고주 배너 / 쿠팡 파트너스
- 기기: 320 / 360 / 390 / 태블릿 / 데스크톱
- 화면: 홈 / 커뮤니티
- 상태: 기본 / 긴 제목 / 긴 설명 / 이미지 오류 / 숨김 메뉴 열림
- 버튼: `실제 화면에서 보기`

### 9.3 실제 경로 미리보기

- 관리자가 `실제 화면에서 보기`를 누르면 만료되는 미리보기 토큰을 만든다.
- 홈 배너는 실제 `/home` 화면, 쿠팡 카드는 실제 `/feed` 화면에서 해당 소재를 강제로 보여준다.
- 관리자 권한과 토큰이 둘 다 있어야 열린다.
- 미리보기 노출과 클릭은 운영 성과에서 제외한다.
- URL을 복사해 일반 사용자에게 전달해도 관리자 권한이 없으면 광고가 보이지 않는다.
- 목적지 검토는 별도 `목적지 새 창에서 확인` 버튼으로 진행한다.

### 9.4 예시 배너

승인 뒤 다음 두 샘플을 직접 만들어 저장한다.

1. 광고주 배너 샘플
   - 중립적인 가상 브랜드와 자체 제작 3:1 이미지
   - `샘플 광고 · 실제 캠페인 아님` 고정
   - 홈 실제 경로에서 레이아웃 확인 가능
2. 쿠팡 카드 샘플
   - 실제 상품이나 쿠팡 이미지를 무단 사용하지 않는 자체 제작 샘플 썸네일
   - 공식 소재가 들어왔을 때의 이미지·제목·설명·고지 배치 확인용
   - 커뮤니티 실제 경로에서 레이아웃 확인 가능

샘플은 관리자 미리보기에서만 보이며 운영 사용자의 성과 데이터에 섞이지 않는다.

## 10. 데이터와 안전장치

### 10.1 추가할 데이터

- 광고주·브랜드 정보
- 캠페인 판매 방식과 금액·부가세
- 계약·입금·세금계산서 상태
- 소재 요청 토큰과 만료일
- 원본 파일과 변환본, 버전, 자동 검사 결과
- 검수 체크리스트와 검수자
- 미리보기 토큰과 만료일
- 슬롯별 예약 기간과 중복 방지 조건
- 광고주 리포트 생성 기록
- 쿠팡 정산월과 확정 수익

### 10.2 필수 차단 조건

다음 중 하나라도 해당하면 승인·예약·송출 버튼을 비활성화한다.

- 직접 배너 기능 플래그가 꺼짐
- 계약 또는 입금 미완료
- 승인 소재 없음
- 정책 버전·검수자·승인 시각 없음
- 이미지 비율·용량·형식 검사 실패
- 목적지가 HTTPS가 아님
- 시작일이 종료일보다 늦음
- 같은 슬롯과 기간에 다른 캠페인이 있음
- 전역·유형·슬롯·캠페인 긴급 중지 중 하나가 켜짐
- 소재 만료일 또는 주장 확인 기한이 지남

### 10.3 개인정보·보안

- 성향 코드, 검사 응답, 결과, 관계 비교 데이터를 광고 결정이나 리포트에 사용하지 않는다.
- 소재 업로드 토큰은 원문을 DB에 저장하지 않고 해시만 저장한다.
- 파일은 서버에서 형식과 실제 내용을 확인하고 실행 가능한 형식을 거절한다.
- 외부 목적지를 서버가 자동으로 읽어오는 방식은 SSRF 위험 때문에 MVP에서 사용하지 않는다.
- 소재 검수 화면에서 외부 링크를 새 창으로 열고 사람이 확인한다.
- 광고 이벤트에는 짧게 유지되는 익명 세션 해시만 사용하며 광고주에게 원시 이벤트를 제공하지 않는다.
- 승인·수정·중지·재활성화·정산 변경을 운영 기록에 남긴다.

## 16. 운영자가 바로 쓸 안내 문구

관리자 화면에서 각 단계의 `답변 예시 보기`를 열면 아래 문구를 복사할 수 있게 한다. 자동 발송하지 않고 운영자가 실제 조건을 확인한 뒤 수정해 보낸다.

### 16.1 첫 문의 답변

```text
안녕하세요, [담당자명]님. 뉴앙 광고·제휴 문의를 확인했습니다.

요청하신 기간과 홈 배너 가능 여부를 검토하고 있습니다. 정확한 제안을 위해 아래 내용을 확인 부탁드립니다.

- 홍보할 브랜드 또는 서비스
- 연결할 최종 웹페이지
- 희망 시작일과 집행 기간
- 배너 소재 준비 여부
- 예상 예산 범위

뉴앙은 개인의 검사 답변이나 성향 정보를 광고 타기팅에 사용하거나 광고주에게 제공하지 않습니다. 확인해 주시면 가능한 일정과 진행 방식을 안내드리겠습니다.

접수번호: [접수번호]
```

### 16.2 제안 안내

```text
안녕하세요, [담당자명]님.

아래 조건으로 뉴앙 홈 배너 집행을 제안드립니다.

- 위치: 홈 추천 화면의 주제검사 3개 다음
- 기간: [시작일] ~ [종료일]
- 판매 방식: 7일 단위 고정 기간
- 금액: 공급가액 [금액]원 + 부가세 [금액]원
- 제공 지표: 노출, 조회 가능 노출, 외부 이동, 숨김·신고 수
- 소재: 1440×480px, JPG/PNG/WebP, 최대 2MB

구매 전환이나 특정 노출 수를 보장하는 상품은 아닙니다. 계약과 입금 확인 뒤 안전한 소재 제출 링크를 보내드리고, 뉴앙의 소재·목적지 검수 뒤 일정을 확정합니다.
```

### 16.3 소재 요청

```text
계약과 입금 확인이 완료되어 배너 소재 제출 링크를 보내드립니다.

- 제출 링크: [만료되는 전용 링크]
- 링크 만료일: [날짜]
- 배너 규격: 1440×480px, 3:1, 최대 2MB
- 허용 형식: JPG, PNG, WebP

링크에서 배너 파일, 브랜드명, 이동 주소와 권리 확인 항목을 제출해 주세요. 제출 뒤 모바일·데스크톱 화면과 광고 문구를 검수하며, 수정이 필요한 경우 구체적인 위치와 사유를 안내드립니다. 최종 승인 전에는 실제 사용자에게 공개되지 않습니다.
```

### 16.4 수정 요청

```text
제출해 주신 배너를 확인했습니다. 아래 항목을 수정해 주세요.

- 수정할 위치: [구체적인 위치]
- 현재 문제: [잘림/가독성/표현/권리/목적지 등]
- 필요한 변경: [완료 조건]

새 제출 링크: [새 버전 링크]
만료일: [날짜]

기존 파일은 공개되지 않으며, 새 파일을 다시 검수한 뒤 최종 일정을 확정합니다.
```

### 16.5 송출 시작 안내

```text
배너 검수와 일정 확인이 완료되어 광고가 시작되었습니다.

- 집행 기간: [시작일시] ~ [종료일시]
- 노출 위치: 뉴앙 홈 추천
- 캠페인 번호: [캠페인 번호]

초기에는 서비스 품질 확인을 위해 단계적으로 노출합니다. 중대한 화면 오류나 정책 문제가 확인되면 광고를 일시 중지하고 바로 안내드리겠습니다.
```

### 16.6 종료·리포트 안내

```text
광고 집행이 종료되어 결과를 공유드립니다.

- 집행 기간: [기간]
- 노출: [수치]
- 조회 가능 노출: [수치]
- 외부 이동: [수치]
- 외부 이동률: [수치]
- 숨김·불편 신고: [수치]
- 중지·보전 내역: [없음 또는 내용]

리포트는 집계 수치만 포함하며 개인의 성향, 검사 결과, 이용 기록은 제공하지 않습니다.
```

### 16.7 가격을 정하지 못했을 때

검증된 이용자 규모와 광고 성과가 충분하지 않은 MVP 초기에는 공개 가격표를 만들지 않는다. 첫 캠페인들은 `초기 파트너 테스트`로 표시하고 기간·업종·제작 지원 범위를 확인해 개별 견적을 낸다. 최소 3개 캠페인의 실제 노출과 운영 시간을 확보한 뒤 별도 가격표 승인 절차를 진행한다.

---

## 17. 최종 승인 요청

다음 내용으로 구현을 시작해도 되는지 확인이 필요하다.

- [ ] MVP는 광고주 삽입 배너와 쿠팡 파트너스 두 종류만 운영한다.
- [ ] 광고주 배너는 홈 추천의 주제검사 3개 뒤 한 곳에만 둔다.
- [ ] 쿠팡 카드는 커뮤니티 추천 게시물 8개 뒤에 둔다.
- [ ] 광고주 배너는 7일 단위 고정 기간·선입금 방식으로 시작한다.
- [ ] 광고주는 계약 뒤 발급받은 전용 링크로 3:1 배너를 제출한다.
- [ ] 샘플은 관리자에게만 실제 홈·커뮤니티 화면에서 보이게 한다.
- [ ] AdSense와 다른 광고 유형은 이번 MVP에서 송출하지 않는다.
- [ ] 성향·검사·관계 데이터는 광고 선택과 광고주 리포트에 사용하지 않는다.

위 항목이 승인되면 이 문서를 기준으로 실제 관리자 페이지와 앱 화면 구현을 시작한다. 수정할 항목이 있다면 체크 항목과 원하는 방향을 함께 기록한다.
