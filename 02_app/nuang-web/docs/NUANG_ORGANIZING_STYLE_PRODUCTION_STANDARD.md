# 뉴앙 정리 방식 제작·운영 명세

- 문서 상태: Production baseline
- 기준일: 2026-07-29
- 상위 표준: `NUANG_TOPIC_ASSESSMENT_PRODUCTION_STANDARD.md`
- 검사 슬러그: `organizing-style`
- 고객용 제목: 나는 일상을 어떻게 정리할까?
- 공개 정책: 전 연령, 내부 lifecycle `pilot`

## 1. Stage 0 주제 선정과 사업 가설

### 사용 장면

사용자는 물건과 자료가 늘었거나, 해야 할 일과 약속이 한꺼번에 생겼거나,
파일·메모를 다시 찾아야 하거나, 공간과 일정이 흐트러졌을 때 “내가 실제로
어떤 정리 행동을 쓰는지” 알고 싶을 수 있다.

### 완료 가치

검사 완료 후 다음을 얻는다.

1. 물건·일정·정보가 들어갈 자리와 분류를 정하는 정도
2. 기억할 내용을 이름·목록·알림으로 바깥에 남기는 정도
3. 현재 생활과 우선순위에 맞춰 정리 방식을 다시 조정하는 정도
4. 생길 때마다 정리하는지, 시간을 따로 내 한꺼번에 정리하는지
5. 정리 대상과 상황에 따라 위 네 행동이 달라지는 지점
6. 현재 뉴앙 코드의 기본 경향과 실제 정리 행동의 교차 해석

### 제품 연결

- 결과 저장과 성향지도·프로필 리포트 연결
- 함께 생활·공부·일하는 사람에게 내가 찾기 쉬운 구조를 설명하는 공유 소재
- 같은 버전 재검사 시 공간·도구·역할 변화에 따른 정리 행동 비교
- 문항 체류·수정·판단 어려움·결과 적합도의 운영센터 자동 집계

### 사업 목표

- 예상 소요 시간: 5분
- 문항 수: 16문항
- 시작 대비 내부 목표 완료율: 78% 이상
- 공유 동기: 함께 쓰는 물건·일정·정보의 위치와 확인 방식을 합의
- 재방문 동기: 이사, 학기·업무·돌봄 역할, 사용하는 도구가 달라진 뒤 변화 확인
- 연령 정책: `all_ages`

### 포트폴리오 중복 판정

| 인접 검사   | 해당 검사가 보는 것                   | 정리 방식이 보는 것                               |
| ----------- | ------------------------------------- | ------------------------------------------------- |
| 집중 전환   | 중단된 일을 다시 시작하는 구체적 행동 | 평소 물건·일정·정보를 찾고 기억하게 만드는 구조   |
| 목표 유지   | 장기 목표를 이어가는 동기와 행동      | 목표의 중요도와 무관한 일상 정리 도구             |
| 미루기 패턴 | 행동 시작이 늦어지는 조건             | 시작 여부가 아니라 저장·상기·재정비 행동          |
| 계획 방식   | 미래 행동의 순서와 시간 계획          | 물리·디지털 정보와 일정에 공통으로 쓰는 관리 행동 |

따라서 주제를 유지하되 “깔끔함”, “성실성”, “생산성”, “정리 능력”의 우열을
측정·평가하지 않는다.

## 2. 구성개념과 경계

### 한 문장 정의

> 최근의 구체적인 일상 정리 상황에서 사용자가 실제로 사용한 안정된 구조,
> 외부 기록, 적응적 재정비, 한꺼번에 정리하는 행동의 정도

### 포함

- 자주 쓰는 물건·자료에 자리나 넓은 분류를 정하는 행동
- 해야 할 일·약속·정보를 이름·목록·알림으로 남기는 행동
- 찾기 어려웠거나 현재 생활과 맞지 않는 위치·순서·규칙을 조정하는 행동
- 정리할 것을 모아두었다가 시간을 따로 잡아 한꺼번에 처리하는 행동
- 물건, 할 일·약속, 파일·메모, 흐트러진 물리 공간 사이의 장면 차이

### 제외

- ADHD, 저장강박, 실행기능 장애, 우울·불안의 선별 또는 진단
- 성실성, 기억력, 생산성, 청결도 또는 도덕성의 우열
- 방이 보이는 상태만으로 정리 기능을 판단하는 평가
- 한 행동을 자주 사용하면 수행과 행복이 반드시 좋아진다는 인과 주장
- 특정 앱, 캘린더, 수납법 또는 미니멀리즘을 정답으로 제시하는 문항

인지적 오프로딩과 개인 정보 관리 연구를 설계에 참고한다. 뉴앙의 네 차원은
기존 성격검사나 임상검사의 번역 척도가 아니며, 일상에서 관찰 가능한 정리
행동을 별도로 구성한 것이다.

## 3. 독립 차원

| 차원                          | 행동 정의                                 | 높은 응답                           | 낮은 응답                          | 금지 해석             |
| ----------------------------- | ----------------------------------------- | ----------------------------------- | ---------------------------------- | --------------------- |
| 자리와 분류 정하기            | 찾을 위치나 넓은 범주를 안정되게 정함     | 여러 정리 장면에서 구조를 자주 만듦 | 최근에는 구조를 드물게 만듦        | 정리 능력·성실성 부족 |
| 기억할 것 남기기              | 이름·목록·알림 등 외부 단서를 남김        | 외부 기록을 자주 사용               | 최근에는 외부 기록을 드물게 사용   | 기억력 부족           |
| 정리 방식 다시 맞추기         | 생활과 우선순위 변화에 맞춰 구조를 조정함 | 구조를 자주 갱신                    | 최근에는 구조를 드물게 갱신        | 변화 적응력 부족      |
| 시간을 잡아 한꺼번에 정리하기 | 쌓인 대상을 별도 시간에 모아 처리함       | 몰아서 정리하는 행동을 자주 사용    | 몰아서 정리하는 행동을 드물게 사용 | 미루기 성격으로 단정  |

네 차원은 서로 반대가 아니며 모두 높거나 낮을 수 있다. 독립 차원을 총점이나
“정리형/비정리형” 하나로 합치지 않는다.

## 4. 공통 상황과 운영 문항

| 상황                                          | 자리와 분류 정하기                      | 기억할 것 남기기                       | 정리 방식 다시 맞추기                    | 시간을 잡아 한꺼번에 정리하기         |
| --------------------------------------------- | --------------------------------------- | -------------------------------------- | ---------------------------------------- | ------------------------------------- |
| 자주 쓰는 물건이 늘어나 제자리를 정해야 할 때 | 용도가 비슷한 물건의 돌아갈 자리를 정함 | 잊기 쉬운 물건의 위치를 메모·표시함    | 사용 빈도에 맞춰 손이 닿는 위치로 옮김   | 한곳에 모았다가 한꺼번에 정리함       |
| 해야 할 일과 약속이 같은 시기에 몰렸을 때     | 목록·달력을 종류·마감·날짜로 나눔       | 해야 할 내용과 시점을 목록·알림에 적음 | 새 일정에 맞춰 기존 순서와 시간을 조정함 | 시간을 잡아 목록·달력을 한꺼번에 정리 |
| 파일·메모·정보를 다시 찾아야 할 때            | 폴더·노트·목록의 저장 위치를 정함       | 검색할 이름·태그·표시를 남김           | 반복해서 찾기 어려운 위치·분류를 바꿈    | 일정량이 쌓인 뒤 한꺼번에 정리함      |
| 방이나 책상에 물건이 쌓여 찾기 어려울 때      | 자주 쓰는 물건부터 돌아갈 자리를 정함   | 처리하기 어려운 물건에 할 일을 표시함  | 맞지 않는 수납 위치·분류를 바꿈          | 시간을 잡아 한 번에 크게 정리함       |

작성 규칙:

- 모든 문항은 최근 4주의 실제 행동 빈도를 묻는다.
- 한 문항에는 한 가지 정리 기능만 둔다.
- 물건·일정·디지털 정보를 한 문항에 섞지 않고 대상을 분명히 쓴다.
- 일정에는 `둘 곳` 같은 물리적 표현을 쓰지 않고 목록·달력·날짜·마감을 쓴다.
- 역문항을 사용하지 않는다.
- 집, 학교, 직장, 돌봄, 취미에 모두 적용 가능한 문장을 사용한다.
- 특정 앱·기기·수납용품을 반드시 사용하도록 요구하지 않는다.
- 판단 어려움 사유는 점수로 환산하지 않는다.

## 5. 채점

- 응답 척도: 거의 하지 않음, 드물게, 때때로, 자주, 거의 항상
- 표시 점수: 1~~5를 0~~100으로 선형 변환
- 공통 상황의 네 문항 중 하나라도 결측이면 그 상황 전체를 차원 비교에서 제외
- 차원당 최소 3개 완전 상황이 있을 때만 차원 점수 표시
- 차원별 평균·최솟값·최댓값·범위·변산성 저장
- 상황 범위가 50점 이상이면 장면 차이를 리포트에서 명시

## 6. 리포트와 주장 연결

리포트 순서:

1. 개인화된 핵심 요약
2. 네 행동별 점수와 빈도 해석
3. 강점·약점·우선 개선 행동
4. 조금씩 정리하는지, 한꺼번에 정리하는지
5. 정리 장면별 차이
6. 네 행동을 연결하는 방법
7. 정리 도구가 오히려 부담이 되는 지점
8. 가까운 사람이 도울 수 있는 방법
9. 다음 10분의 작은 정리
10. 개인 전략보다 공간·역할·도구 조건 조정이 먼저인 경우
11. 뉴앙 코드와 이번 결과의 교차 해석

## 7. 연구 근거 원장

| 연구                      | 설계 반영                              | 일반화 제한                                                |
| ------------------------- | -------------------------------------- | ---------------------------------------------------------- |

## 10. 공개 후 운영

문항·도구 버전당 첫 30건 미만은 자동 수정하지 않는다. 이후 운영센터의 검사
품질 자동 검수에서 모호함, 경험 없음, 상황 의존, 반복 수정, 결과 불일치 신호를
확인한다. 기준은 상위 제작·운영 표준과 동일하게 적용한다.

운영 시스템은 수정 후보와 변경 비교를 만들 수 있지만 문항 의미, 채점 또는 공개
버전을 자동으로 바꾸지 않는다. 운영자가 변경 등급을 확인하고 새 버전을 승인한다.
